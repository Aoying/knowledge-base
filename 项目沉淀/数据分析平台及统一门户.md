# 数据分析平台及统一门户（交通银行总行测试中心）

## 项目概述

平台分两大块：

- 数据分析平台：建设统计分析管理模块，提供多维度数据可视化、趋势分析、自动告警与自助下载服务，提高数据支撑能力
- 统一门户：提供一站式访问平台服务，作为一体化测试管理平台的主入口，汇聚各模块、工具的任务信息，为用户提供一站式访问各个测试工具平台的通道

任职：深圳市法本信息技术股份有限公司（2024/4 至今期间项目）。

## 软件环境

- 后端：JUMP + OceanBase + MyBatis + Elasticsearch + Redis
- 开发工具：IDEA + Git

## 本人职责

1. 统一门户系统管理下的用户管理，以及门户首页待办、风险、质量等功能的接口设计和表设计
2. 用户相关操作变更记录的接口设计、表设计及开发
3. 系统管理下的部门、项目组、用户、岗位等相关数据和多子系统的数据上下游同步设计及开发
4. 数据分析平台的系统管理及用户登录相关开发
5. 前后端联调及测试，SIT、UAT、PROD 发版

## 核心工作与技术点

- 多子系统数据上下游同步：组织架构类基础数据（部门/项目组/用户/岗位）在多个子系统间保持一致
- 操作变更记录：用户关键操作的留痕设计（表设计 + 接口）
- 门户聚合：多系统任务信息汇聚到统一首页待办
