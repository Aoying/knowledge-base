# 督办系统（上海农商行）

## 项目概述

为上海市农村商业银行开发的督办流程管理平台，服务于行长、部门负责人等中高层管理人员，实现事项督办、流程审批、任务追踪、移动办公等功能，支持 PC 与 App 双端操作，提升事务处理效率与流程闭环监管能力。

任职：深圳市法本信息技术股份有限公司（2024/4 至今期间项目）。

## 软件环境

- 后端：Spring Boot + MySQL + MyBatis + Redis + Flowable
- 前端：Vue
- 开发工具：IDEA + Gitee

## 本人职责

1. 负责督办系统日常需求设计、开发及优化
2. 负责督办系统前端、后端、App 上线
3. 负责系统信创改造
4. 参与项目需求讨论、项目测试及需求发版上线
5. 负责系统新流程创建及老流程的优化维护
6. 其他业务流程逻辑代码的修改与优化

## 核心工作与技术点

- 基于 Flowable 的流程模块设计与开发：编写流程模型 XML，配置监听器实现自动通知、节点权限控制、动态处理人分配
- 开发移动端接口与 Web 管理后台，支持任务推送、流程图展示、事项统计导出
- 信创改造：国产化环境适配与上线
