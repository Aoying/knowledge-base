# 翼安反诈平台（96110）

## 项目概述

96110「翼安反诈」云平台是一个集约开发、统一运营、模块化部署的平台，主要包括预警洞察中心、反制拦截中心、96110 反诈劝阻咨询中心、网址拦截策略管理、反诈大数据智能分析中心、预警数据治理中心等业务模块。针对诈骗事件进行预警拦截，结合中国电信 96110 全国云呼能力优势，形成多渠道劝阻的全流程反诈解决方案，为政法公安行业客户提供一站式反诈 SaaS 应用交付服务。

任职：上海欣方智能系统有限公司（2022/6 – 2023/7）。

## 软件环境

- 后端：MySQL + Spring Cloud + JPA + Redis + Elasticsearch + HBase + Kafka + RocketMQ
- 开发工具：IDEA + Git

## 本人职责

1. 主要负责预警数据业务模块、双呼模块的开发
2. 参与预警数据预处理模块、数据处理模块、预警数据中心的流程优化及 Bug 修复
3. 预警黑名单设计及实现
4. 参与宣传模块的设计开发
5. 参与视频名片业务平台的设计开发
6. 参与项目需求讨论、项目测试及需求发版上线

## 核心工作与技术点

- 预警数据链路：预处理 → 数据处理 → 预警数据中心 → 预警业务模块
- 双呼模块：依托云呼能力的劝阻外呼
- 黑名单：预警黑名单的数据结构与命中拦截设计
