# 解抵押平台（农业银行重庆分行）

## 项目概述

结合农业银行重庆分行的调研，对重庆抵押车业务做统一管理，方便业务协调，降低不法分子利用漏洞二次抵押等风险。项目通过农业银行重庆分行试点，逐渐辐射重庆其他各大分行及其他金融机构，通过线上平台简化车辆的抵解押操作。主要包括抵押（申请、审核、办理）、解押（申请、审核、办理）、车辆风险监控等服务模块，及抵解押的流程与业务责任细分、业务模块自定义配置、人脸识别、业务定位。

任职：重庆数软信科科技有限公司（2018/6 – 2020/6）。

## 软件环境

- 后端：MySQL / Oracle + Spring Boot + MyBatis-Plus + Redis
- 前端：JS + CSS + Vue + Nginx
- 开发工具：IDEA + WebStorm + Git

## 本人职责

1. 参与数据库的设计与创建
2. 抵解押业务模块的自定义配置模块
3. 后台用户、App 用户、银行与金融机构的管理模块
4. 短信、App 消息推送模块
5. 银行内网所需：将项目所有 MySQL 自定义 SQL 语句替换为 Oracle
6. 参与后期摆渡系统的设计和代码实现
7. 参与项目测试、客户方项目会议、正式服与测试服的打包部署

## 核心工作与技术点

- 业务自定义配置：抵解押流程与业务模块的可配置化
- 多渠道消息推送：短信 + App 推送（策略模式可扩展）
- 数据库迁移：MySQL 自定义 SQL 全量替换为 Oracle 方言
- 摆渡系统：内网数据摆渡的设计与实现
