# 交通银行企业网银

## 项目概述

交行企业网银是以互联网为基础，以交通银行资金清算系统和核心系统为依托，使用 CA 认证的商业银行网络服务系统。企业网银用户分为普通用户（网银客户号、用户名和密码登录）和证书用户（使用存储在 USBKey 内的数字证书和密码登录）。企业网银提供基本服务区、蕴通服务区、专项服务区、配置服务区四个服务区，每个服务区分布不同的网银功能菜单，客户可通过选择服务区迅速找到所需要的功能。

任职：北京宇信科技集团股份有限公司（2020/6 – 2022/4）。

## 软件环境

- 后端：Spring Boot + DB2 + Redis
- 前端：JS + CSS + JSP
- 开发工具：Eclipse + ClearCase + ClearQuest

## 本人职责

1. 主要参与负责速融通、代发、业务签约、公务卡模块
2. 对应模块的需求分析及代码实现
3. 修复测试人员提出的缺陷
4. 代发模块（本行、他行代发）业务逻辑及代码整理

## 核心工作与技术点

- 代发业务：本行代发与他行代发的业务逻辑梳理与代码整理
- 证书用户体系：USBKey 数字证书登录的业务侧配合
