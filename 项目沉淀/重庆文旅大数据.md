# 重庆文旅大数据

## 项目概述

结合重庆文旅要求，对重庆各景区旅游数据做集中展示，方便各区县文旅局对本地文化旅游资源的把控和调整。后台运用 Spring Boot 框架，通过 Spring Security 设计权限，按市级和区县级区分对资源信息进行限制。主要包括月报（年报、季报）分析、各景区（博物馆）数据汇总；App 端后续增加景区、博物馆、演艺馆的收藏功能、视频浏览记录、文档在线阅览等。

任职：重庆数软信科科技有限公司（2018/6 – 2020/6）。

## 软件环境

- 后端：MySQL + Spring Boot + Spring JPA + Redis
- 前端：JS + CSS + Vue + Nginx
- 开发工具：IDEA + VS Code + Git

## 本人职责

1. App 端的第三方数据查询、统计接口
2. 收藏功能、视频历史浏览的数据库设计、功能设计与实现
3. 文献、报表、报告、公报、年鉴等的在线浏览、下载功能
4. 使用 AOP 完成接口参数解密及返回值的加密功能
5. WebService 调用、对接气象局接口
6. 参与项目测试、客户方项目会议、测试环境的打包部署

## 核心工作与技术点

- 权限设计：Spring Security + 市级/区县级数据权限隔离
- AOP 加解密：接口入参解密、返回值加密的切面实现
- 第三方对接：气象局接口（WebService）与 App 端数据统计接口
