# 快捷键速查

> IDEA / VSCode / Windows。肌肉记忆清单，每晚 20:30 可增补。

## IntelliJ IDEA（Win）

| 按键 | 动作 |
|---|---|
| `Shift Shift` | 全局搜索（文件/类/符号） |
| `Ctrl+N` / `Ctrl+Shift+N` | 找类 / 找文件 |
| `Ctrl+E` | 最近打开的文件 |
| `Alt+Enter` | 万能修复（导包、生成、 quick fix） |
| `Ctrl+Alt+L` | 格式化代码 |
| `Ctrl+Alt+O` | 优化 import |
| `Shift+F6` | 重命名（重构） |
| `Ctrl+Alt+M` / `Ctrl+Alt+V` | 抽方法 / 抽变量 |
| `F8` / `F7` / `Shift+F8` | 调试：步过 / 步入 / 步出 |
| `Ctrl+F8` | 行断点开关 |
| `Alt+F8` | 调试时算表达式 |
| `Ctrl+Shift+F` | 全局文本搜索 |
| `Ctrl+Shift+R` | 全局替换 |
| `Ctrl+H` | 类继承结构 |
| `Ctrl+Q` | 快速看文档 |

## VSCode（Win）

| 按键 | 动作 |
|---|---|
| `Ctrl+P` | 快速打开文件 |
| `Ctrl+Shift+P` | 命令面板 |
| `Ctrl+`` | 开关终端 |
| `Ctrl+D` | 选中下一个相同词（多光标） |
| `Alt+Up/Down` | 整行上下搬 |
| `Shift+Alt+Up/Down` | 整行复制 |
| `Ctrl+/` | 行注释开关 |
| `F12` / `Alt+F12` | 跳定义 /  peek 定义 |
| `Ctrl+Shift+O` | 文件内符号搜索 |

## Windows

| 按键 | 动作 |
|---|---|
| `Win+E` | 资源管理器 |
| `Win+D` | 显示桌面 |
| `Win+L` | 锁屏 |
| `Win+Tab` | 任务视图 / 虚拟桌面 |
| `Win+Ctrl+D` / `Win+Ctrl+←→` | 新建虚拟桌面 / 切换 |
| `Win+V` | 剪贴板历史（先开一次启用） |
| `Win+.` | Emoji / 符号面板 |
| `Win+Shift+S` | 截图 |
| `Alt+Tab` / `Win+Tab` | 切窗口 |
| `Win+R` → `cmd` / `powershell` | 运行 |
