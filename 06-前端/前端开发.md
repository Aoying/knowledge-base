# 前端开发

Java 后端视角的前端知识：目标是能看懂前端代码、顺畅联调、能独立做轻量页面/管理面板。框架细节按需深入，不做前端工程师式深挖。

> 时效性：版本信息 2026-10-17 已验证（见来源链接）。

## 三件套速览

- **HTML**：语义化标签（`header/main/article/section`），表单与输入校验属性。
- **CSS**：布局只记两套——Flex（一维）+ Grid（二维）；响应式靠媒体查询，日常够用。
- **JavaScript**：ES6+ 语法（解构、箭头函数、Promise/async、模块）→ 详见 [02-开发语言/JavaScript.md](02-开发语言/JavaScript.md)。

## 现代工具链（2026）

- **Node.js 24 LTS**：前后端都用 JS 时的运行环境，包管理用 npm/pnpm。
- **Vite 6/7**：当前默认构建工具（dev 秒启、打包 Rollup），Vue/React 新项目都用它脚手架。
- 浏览器 DevTools 的 Network 面板是联调第一现场。

## 后端联调要点

- **CORS**：前后端分离必配。后端（Spring Boot）放行来源、方法、头；预检请求（OPTIONS）别被拦截器拦了。
- **REST 约定**：资源名词复数、HTTP 动词表语义、状态码表结果（200/201/400/401/403/404/500）。
- **fetch 示例**：

```js
const res = await fetch('/api/chapters?page=1', {
  headers: { 'Authorization': 'Bearer ' + token }
});
if (!res.ok) throw new Error(`HTTP ${res.status}`);
const data = await res.json();
```

- **时间/数字坑**：前后端统一用 ISO 8601 / 时间戳传时间；金额用字符串或分单位，别用 float 裸传。

## 5 个常见坑

1. **跨域调不通先看 Network**：是 CORS 预检失败、CORS 头缺失，还是后端根本没收到请求，三者排查路径完全不同。
2. **缓存背刺**：静态资源文件名不带 hash，发版后用户看到旧页面；Vite 默认带 hash，手动拷文件时注意。
3. **时区**：`new Date()` 用的是浏览器本地时区，和后端 UTC 对不上是常态，传输统一用 UTC 时间戳。
4. **大列表卡顿**：几千行直接渲染必卡，虚拟滚动（只渲染可视区）是标准解。
5. **XSS**：用户输入拼进 `innerHTML` 就是漏洞；用 `textContent` 或框架默认转义，富文本走白名单过滤。
