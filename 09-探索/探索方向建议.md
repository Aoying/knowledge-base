## 候选方向

### 1. 本地 RAG 进阶（生产化）

- **研究价值**：你的 ChromaDB + EmbeddingGemma2 原型是能跑的 demo，离生产还差：混合检索（关键词+向量）、reranker 重排、chunk 策略调优。这些是 RAG 落地的真正分水岭。
- **入门路径**：先在现有原型上加一个 reranker（如 bge-reranker 的 Ollama/本地版本）做对比实验，用同一批查询看召回质量变化。
- **与现有知识的联系**：[02-开发语言/Python.md](02-开发语言/Python.md)（sqlite3/requests）、[01-AI与Agent/Agent.md](01-AI与Agent/Agent.md)（Memory 检索策略）、[01-AI与Agent/RAG-Skills.md](01-AI与Agent/RAG-Skills.md)。
- **可实践项目**：给 ob_note 做一个本地问答——"我的笔记里关于 flowable 补偿说了什么"，Ollama + Chroma 全本地。

### 2. Agent 评测与可观测

- **研究价值**：Agent 最大的坑是"不知道它什么时候在瞎搞"。评测（任务成功率、工具调用准确率、token 消耗）和 trace 可观测是 Agent 从 demo 到可用的必经之路。
- **入门路径**：给小说引擎的抽取 Agent 加三件事：每次调用记 trace（输入/工具/输出）、抽查 20 个章节人工打分、统计 token 成本。
- **与现有知识的联系**：[01-AI与Agent/Agent.md](01-AI与Agent/Agent.md)（循环控制、Human-in-the-loop）、[01-AI与Agent/开发工作流-Skills.md](01-AI与Agent/开发工作流-Skills.md)（superpowers 的 TDD/review 纪律可直接套用）。
- **可实践项目**：一个极简的 Agent trace 查看器（SQLite 存 trace，网页列出来）。

### 3. Godot 入门（做小游戏）

- **研究价值**：Godot 轻量、开源、GDScript 上手快，适合利用碎片时间做一个小 demo，对理解"游戏循环/状态机"也有帮助——和你流程引擎的背景是相通的。
- **入门路径**：官方 Getting Started 跑通一个 2D 小游戏（官方文档有完整教程），再试 TileMap 和信号（signal）机制。基础概念已整理：[07-游戏/Godot.md](07-游戏/Godot.md)（2026-10-17 补全，版本/核心概念/5 坑）。
- **与现有知识的联系**：[01-AI与Agent/Agent.md](01-AI与Agent/Agent.md)（状态机思维）、[02-开发语言/Python.md](02-开发语言/Python.md)（GDScript 语法接近 Python）。
- **可实践项目**：给《无空剑门》做一个像素风小场景 demo（蛊田/演武场），和视频项目联动。

### 4. 前端可视化（给知识库/小说引擎做面板）

- **研究价值**：你的小说引擎现在是 SQLite + 命令行，人物关系、时间线、伏笔台账如果能可视化（关系图谱、时间轴），调试和创作体验会质变。
- **入门路径**：先学一个轻量方案——ECharts 关系图 + 时间轴，数据直接从 SQLite 读；不用上重型框架。前端基础已整理：[06-前端/前端开发.md](06-前端/前端开发.md)（2026-10-17 补全，框架选型/联调/5 坑）。
- **与现有知识的联系**：[06-前端/前端开发.md](06-前端/前端开发.md)、[02-开发语言/JavaScript.md](02-开发语言/JavaScript.md)、[02-开发语言/Python.md](02-开发语言/Python.md)（sqlite3）。
- **可实践项目**：小说引擎的人物关系图谱页面（从 Relation 表读数据渲染）。

### 5. AI 桌宠 / Electron 桌面应用

- **研究价值**：2026-10-18 已立项意向。dsh-pet（MIT，DIY 素材链）/ VPet（Apache-2.0，WPF）/ LingChat（Rust，AI 陪聊+表情）三个候选已调研；dsh-pet 有独立模式 + 本机 HTTP 接口，可桥接你本地 Ollama 做零成本"自言自语"。
- **入门路径**：`npm install -g dsh-pet` + `dsh-pet-standalone` 先体验手感；再研究 pet pack（照片 rembg → 透明 PNG → pet pack）+ Ollama 桥接。
- **与现有知识的联系**：[06-前端/前端开发.md](06-前端/前端开发.md)（Electron 本质是前端）、[02-开发语言/Python.md](02-开发语言/Python.md)（rembg 抠图链）。
- **可实践项目**：最小可玩版"独立版 + 照片形象 + Ollama 自言自语"。

### 6. 本地语音交互（STT + TTS）

- **研究价值**：桌宠/小说引擎的下一层交互是"开口说话"：本地 STT（whisper.cpp）+ Ollama + 本地 TTS，全链路零 API 成本；和视频项目的 TTS→SadTalker 管线复用一半。
- **入门路径**：whisper.cpp 跑通实时转写；TTS 先用 edge-tts（免费）过渡，再试本地模型。
- **与现有知识的联系**：视频项目的 TTS 资料（`tts_dialogue.txt`）、Ollama 本地接口。
- **可实践项目**：给桌宠加上"语音输入→Ollama→语音回复"。
