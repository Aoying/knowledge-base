# 看板-读书追踪

> 看板思路参考：[dmscode/Obsidian-Templates](https://github.com/dmscode/Obsidian-Templates)（Dataview 系列）

用「模板-读书笔记」创建的读书笔记会自动汇总到这里（按 `tags: [读书]` 识别）。

```dataview
TABLE author AS 作者, status AS 状态, rating AS 评分, start_date AS 开始读
FROM #读书
SORT status ASC
```

## 在读
```dataview
TABLE author AS 作者, rating AS 评分
FROM #读书
WHERE status = "在读"
```
