# 看板-笔记统计

> [!info] 知识库体检面板：哪里在涨，哪里在荒
> 口径：领域 = 文件夹一级目录；层级取 Frontmatter 的层级字段；管理文件（效率工具、知识地图、README、规范、标签索引）不计入孤岛统计；长期未更新以 Frontmatter 更新日期为准，不用 file.mtime（同步后 mtime 不可靠）。
> 导航：[[总览]] · [[README]] · [[标签索引]]

## 各领域笔记数

```dataview
TABLE length(rows) AS 笔记数
FROM ""
GROUP BY choice(file.folder = "", "根目录", split(file.folder, "/")[0]) AS 领域
SORT length(rows) DESC
```

## 各目录笔记数（看子目录结构）

```dataview
TABLE length(rows) AS 笔记数
FROM ""
GROUP BY choice(file.folder = "", "根目录", file.folder) AS 目录
SORT length(rows) DESC
```

## 层级分布（只计带层级字段的内容笔记）

```dataview
TABLE length(rows) AS 笔记数
FROM ""
WHERE 层级
GROUP BY 层级
SORT length(rows) DESC
```

## 标签统计 Top 20

```dataview
TABLE length(rows) AS 笔记数
FROM ""
FLATTEN flat(list(标签, tags)) AS 标签
WHERE 标签
GROUP BY 标签
SORT length(rows) DESC
LIMIT 20
```

## 最近修改的 15 篇

```dataview
TABLE file.mtime AS 修改时间
FROM ""
SORT file.mtime DESC
LIMIT 15
```

## 近 30 天新增

```dataview
TABLE file.folder AS 目录, file.mtime AS 修改时间
FROM ""
WHERE file.mtime >= date(today) - dur(30 days)
SORT file.mtime DESC
LIMIT 30
```

## 长期未更新（更新日期超过 180 天，只计带更新日期字段的笔记）

```dataview
TABLE 更新日期 AS 更新日期, file.folder AS 目录
FROM ""
WHERE 更新日期 AND date(更新日期) < date(today) - dur(180 days)
SORT date(更新日期) ASC
LIMIT 30
```

## 孤岛笔记（无入链，排除管理文件）

```dataview
TABLE file.folder AS 目录
FROM ""
WHERE length(file.inlinks) = 0 AND !contains(file.path, "效率工具/") AND !contains(file.path, "知识地图/") AND file.name != "README" AND file.name != "知识库规范" AND file.name != "标签索引"
SORT file.name ASC
```
