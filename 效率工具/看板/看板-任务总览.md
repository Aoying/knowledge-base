## 未完成任务（按领域分组）

```dataview
TASK
FROM ""
WHERE !completed
GROUP BY choice(file.folder = "", "根目录", split(file.folder, "/")[0]) AS 领域
SORT 领域 ASC
```

## 已逾期

```dataview
TASK
FROM ""
WHERE !completed AND due AND due < date(today)
SORT due ASC
```

## 最近完成的 20 条

```dataview
TASK
FROM ""
WHERE completed
SORT completion DESC
LIMIT 20
```
