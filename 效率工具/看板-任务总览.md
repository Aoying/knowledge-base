# 看板-任务总览

> 看板思路参考：[dmscode/Obsidian-Templates](https://github.com/dmscode/Obsidian-Templates)（Dataview 系列）

Dataview 实时查询，全库任务一屏看完。

## 未完成任务（按文件分组）
```dataview
TASK
FROM ""
WHERE !completed
GROUP BY file.link
```

## 已逾期
```dataview
TASK
FROM ""
WHERE !completed AND due AND due < date(today)
SORT due ASC
```

## 最近完成的 20 条
```dataview
TASK
FROM ""
WHERE completed
SORT completion DESC
LIMIT 20
```
