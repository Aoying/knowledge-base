# 看板-笔记统计

> 看板思路参考：[dmscode/Obsidian-Templates](https://github.com/dmscode/Obsidian-Templates)（Dataview 系列）

知识库体检面板：哪里在涨，哪里在荒。

## 各分组笔记数
```dataview
TABLE length(rows) AS 笔记数
FROM ""
GROUP BY split(file.folder, "/")[0] AS 分组
SORT length(rows) DESC
```

## 标签统计 Top 20
```dataview
TABLE length(rows) AS 笔记数
FROM ""
FLATTEN file.tags AS 标签
GROUP BY 标签
SORT length(rows) DESC
LIMIT 20
```

## 最近修改的 15 篇
```dataview
TABLE file.mtime AS 修改时间
FROM ""
SORT file.mtime DESC
LIMIT 15
```
