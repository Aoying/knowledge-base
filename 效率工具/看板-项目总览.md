# 看板-项目总览

> 看板思路参考：[dmscode/Obsidian-Templates](https://github.com/dmscode/Obsidian-Templates)（Dataview 系列）

用「模板-项目管理」创建的项目笔记会自动汇总到这里（按 `tags: [项目]` 识别）。

```dataview
TABLE status AS 状态, start_date AS 开始, deadline AS 截止
FROM #项目
SORT deadline ASC
```

## 进行中的项目任务
```dataview
TASK
FROM #项目
WHERE !completed
GROUP BY file.link
```
