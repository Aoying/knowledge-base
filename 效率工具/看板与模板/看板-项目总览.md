## 项目状态分布

```dataview
TABLE length(rows) AS 项目数
FROM #项目
GROUP BY status AS 状态
SORT length(rows) DESC
```

## 全部项目（按截止排序）

```dataview
TABLE status AS 状态, start_date AS 开始, deadline AS 截止
FROM #项目
SORT deadline ASC
```

## 进行中的项目任务

```dataview
TASK
FROM #项目
WHERE !completed
GROUP BY file.link
```
