# 看板-读书追踪

> [!info] 读书进度一览
> 用「模板-读书笔记」创建的读书笔记会自动汇总到这里（按 `tags: [读书]` 识别）。
> 导航：[[README]]

## 阅读状态分布

```dataview
TABLE length(rows) AS 本数
FROM #读书
GROUP BY status AS 状态
SORT length(rows) DESC
```

## 全部书目

```dataview
TABLE author AS 作者, status AS 状态, rating AS 评分, start_date AS 开始读
FROM #读书
SORT status ASC
```

## 在读

```dataview
TABLE author AS 作者, rating AS 评分
FROM #读书
WHERE status = "在读"
```

## 已读（按评分排序）

```dataview
TABLE author AS 作者, rating AS 评分, finish_date AS 读完
FROM #读书
WHERE status = "已读"
SORT rating DESC
```
