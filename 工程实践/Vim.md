# Vim

> 每晚 20:30 自动补充完善。先记住：Vim 是模式编辑器，`Esc` 回到普通模式是所有操作的前提。

## 模式

- **普通模式**（Normal）：移动、删除、复制，打开即是
- **插入模式**（Insert）：`i`（光标前）/`a`（光标后）/`o`（下方新行）/`O`（上方新行）进入，`Esc` 退出
- **可视模式**（Visual）：`v` 字符选择 / `V` 行选择 / `Ctrl-v` 块选择
- **命令模式**：`:` 输入命令，`/` 搜索

## 移动（普通模式，肌肉记忆优先级最高）

```
h j k l        左 下 上 右
w / b          下一个词头 / 上一个词头
0 / $          行首 / 行末
gg / G         文件头 / 文件尾
:n / nG        跳到第 n 行
%              跳到匹配的括号
Ctrl-f / Ctrl-b   翻页下 / 上
*              搜索光标处单词
```

## 编辑

```
x        删一个字符
dd       删整行；5dd 删 5 行
dw / d$  删到词尾 / 行尾
yy       复制整行；p 粘贴到下方，P 上方
u / Ctrl-r   撤销 / 重做
.        重复上一次修改（神器）
>> / <<  行缩进 / 反缩进
```

## 搜索替换

```
/关键字    向下搜索，n 下一个，N 上一个
:%s/旧/新/g        全文替换
:%s/旧/新/gc       逐个确认替换
:s/旧/新/g         仅当前行
```

## 分屏与标签

```
:sp 文件名    横分屏；:vsp 文件名  竖分屏
Ctrl-w w      切分屏；Ctrl-w h/j/k/l  方向切
:tabnew       新标签页；gt / gT  切换
```

## 退出保存

```
:w      保存；:w! 强制保存
:q      退出；:q! 不保存退出
:wq / :x   保存退出
ZZ      保存退出（普通模式快捷）
```

## 常用配置（~/.vimrc）

```vim
set number relativenumber   " 行号 + 相对行号
set tabstop=4 shiftwidth=4 expandtab  " 4 空格缩进
set ignorecase smartcase    " 搜索忽略大小写（有大写时敏感）
set hlsearch incsearch      " 高亮 + 增量搜索
syntax on                   " 语法高亮
set clipboard=unnamedplus   " 与系统剪贴板互通（需 +clipboard）
```

## 5 个常见坑

1. **卡在插入模式出不来**：狂按 `Esc` 回到普通模式再操作；`:q!` 强制退出不保存。
2. **方向键乱码**：终端类型不对，先 `Esc` 再 `:set term=ansi` 或换个终端。
3. **粘贴代码缩进错乱**：粘贴前 `:set paste`，粘完 `:set nopaste`。
4. **`u` 撤销不够用**：Vim 撤销是树状的，`g-` / `g+` 按时间回退分支。
5. **想用鼠标**：`:set mouse=a` 开启鼠标支持（终端 Vim）。

## 疑难杂症

### 1. 远程粘贴代码缩进全乱（bracketed paste）
- **现象**：从本地复制大段代码粘到远程 vim，每行缩进越来越深。
- **原因**：开了 `autoindent`，粘贴时 vim 把每行都当手打的又缩进一次。
- **解决**：粘贴前 `:set paste`，粘完 `:set nopaste`；或用 `"+p` 走系统剪贴板（需 +clipboard）；新版 vim/neovim 一般自动处理 bracketed paste。

### 2. 打开文件提示 swap 文件已存在
- **现象**：`Found a swap file by the name ...`，问你要恢复还是删除。
- **原因**：上次 vim 非正常退出（断网、kill），swap 残留；或另一个 vim 正开着这文件。
- **解决**：确认没别的 vim 在编辑，选 `D` 删除 swap；经常断网的话把 `directory` 指到本地 tmp，避免残留。

## 最小可用 vimrc

```vim
" ~/.vimrc（Windows 下是 ~/_vimrc）
set nocompatible
syntax on
set number relativenumber
set tabstop=4 shiftwidth=4 expandtab
set autoindent smartindent
set ignorecase smartcase        " 搜索忽略大小写，有大写时区分
set incsearch hlsearch
set mouse=a
set clipboard=unnamedplus       " 和系统剪贴板互通（需 +clipboard）
set encoding=utf-8
set nobackup noswapfile         " 不想要 .swp 残留就关掉
" jk 快速退出插入模式
inoremap jk <Esc>
" 空格当 leader 键
let mapleader=" "
nnoremap <leader>w :w<CR>
nnoremap <leader>q :q<CR>
```

- 改完 `:source ~/.vimrc` 即时生效，不用重启。
- 想再进一步直接上 Neovim + lazy.nvim，但先把原生 vim 玩熟。

## 多文件：buffer / window / tab

```vim
:e file2.py        " 再开一个文件（当前窗口切换，旧文件进 buffer）
:ls               " 列出所有 buffer
:b2               " 切到 2 号 buffer
:bn / :bp         " 下一个 / 上一个 buffer
:bd               " 关掉当前 buffer

:sp file3.py      " 横向分屏
:vsp file4.py     " 纵向分屏
Ctrl+w h/j/k/l    " 分屏间跳转
Ctrl+w =          " 分屏等宽

:tabnew file5.py  " 新标签页
gt / gT           " 标签页左右切
```

- 一句话区分：buffer 是"打开的文件"，window 是"看 buffer 的格子"，tab 是"格子的布局"。
- 日常够用组合：`buffer + 分屏`，tab 很少需要。

## 宏录制（重复劳动终结者）

```vim
qa          " 开始录制到寄存器 a
I"<Esc>A",<Esc>j   " 示例操作：行首加引号、行尾加逗号、下一行
q           " 结束录制
@a          " 执行一次
10@a        " 执行 10 次
@@          " 再来一次上次的宏
```

- 批量改 100 行格式：录 3 秒，`99@a`，喝咖啡。
- 宏存在寄存器里，`:reg a` 查看；复杂宏可以粘出来存进 vimrc 长期用。

## 基础知识补强

### 核心概念与术语

- Vim 的核心不是背命令，而是学一门「编辑语言」：动词 + 移动 = 一次编辑动作。
- 动词（operator，操作符）：`d` 删除、`c` 修改、`y` 复制、`>` 右缩进、`<` 左缩进、`=` 自动格式化。
- 移动（motion）：`w` 词头、`e` 词尾、`b` 词首、`$` 行尾、`0` 行首、`f<char>` 跳到本行某字符、`%` 匹配括号。
- 文本对象（text object）：把「一整块文本」当操作目标，如一个词、一对引号里的内容、一个括号块。
- 计数（count）：动词或移动前的数字是倍数，如 `3` 表示做 3 次，动词和移动两边都带数字时是相乘。
- 寄存器（register）：剪贴板家族，删除和复制的内容都先进寄存器，`p` 粘贴的是寄存器内容。
- 标记（mark）：在文件里打的书签，`m` 加字母设置，大写字母标记跨文件也有效。
- 跳转表（jumplist）：光标的大步移动历史（搜索、跳行、跳定义），可以前进后退。
- 变更表（changelist）：每次修改的位置历史，和跳转表分开记。
- 命令行模式（Ex 模式）：按 `:` 后输入的是 Ex 命令，本质是面向「行范围」的批量操作。
- 单字符命令背后有规律：大写常常是小写的「加强版」或「反方向版」，如 `p/P`、`o/O`、`n/N`。
- 理解这套组合语法后，新命令不用背：先想「我要对哪块文本做什么」，再拼出来即可。

### 基础语法与用法

动词 + 移动的基本拼接（普通模式下直接敲）：

```
dw        删除到下一个词头（delete word）
de        删除到词尾
d$        删除到行尾，同 D
cw        删到词尾并进入插入模式（change word）
yy        复制整行；yw 复制一个词
ciw       修改整个词并进入插入模式，不管光标在词的哪个位置
3dd       删除 3 行；d2w 删除 2 个词
gUw       把一个词变大写；gu$ 把到行尾变小写
```

文本对象：`i` 表示「里面」（inner，不含包围符号），`a` 表示「一整块」（a/around，含包围符号）。

```
ciw       改一个词的内容
caw       改一个词连同它后面的空格
ci"       改双引号里面的内容（写日志模板、改配置常用）
ca"       改引号连同内容
ci(       改括号里面的内容，ci[、ci{、ci< 同理
di(       删括号里面的内容
vi(       选中括号里面的内容
vat       选中一整个 HTML/XML 标签块
dap       删除一整段（paragraph，连同段尾空行）
```

带范围的 Ex 命令，格式是「范围 + 命令」，范围可以是行号、`%`（全文）、`.`（当前行）、`$`（末行）：

```
:3,10d            删除第 3 到 10 行
:%d               删除全文
:.,$s/old/new/g   从当前行到文件尾做替换
:10,20y           复制第 10 到 20 行到默认寄存器
:g/DEBUG/d        删除所有含 DEBUG 的行（g 是 global，在匹配行上执行命令）
:g!/release/s/$/;/  在不含 release 的行末尾加分号
:v/pattern/d      v 是 g 的反面：在不匹配的行上执行
```

寄存器与粘贴进阶：

```
"ayy        复制整行到寄存器 a（a 可换成任意小写字母）
"ap         粘贴寄存器 a 的内容，互不干扰
"+y         复制到系统剪贴板（需 +clipboard 支持）
"_d         删进「黑洞寄存器」，不污染任何寄存器
:reg        查看所有寄存器内容
```

标记与跳转：

```
ma          在当前位置设标记 a
'a          跳到标记 a 所在行行首；`a 跳到精确位置
`.          跳回上次修改的位置（反引号 + 点）
Ctrl-o      跳转表后退（去过的地方）
Ctrl-i      跳转表前进（注意：和 Tab 是同一个键位信号）
:marks      查看全部标记
```

插入模式里的小动作：

```
Ctrl-w      删除光标前一个词（打错词不用退回普通模式）
Ctrl-u      删除光标前本行全部已输入内容
Ctrl-t / Ctrl-d   本行增加 / 减少一级缩进
Ctrl-r 0    把最近复制的内容贴进来
```

查帮助（自带说明书，比网上搜快）：

```
:help ciw           查某个命令
:help motion        查一个概念
:help 'tabstop'     查某个选项（选项名带单引号）
Ctrl-] / Ctrl-t     在帮助里跟着链接跳 / 跳回
```

### 关键机制速览

- 组合优先于记忆：Vim 命令总数吓人，但拆开都是「计数 × 动词 × 移动/对象」，掌握约 10 个动词和 15 个移动就能拼出绝大多数日常操作。
- `d` 和 `c` 的区别只有一个：`c` 做完删除会进入插入模式；效果上 `cw` 特殊，行为等同 `ce`（改到词尾），这是历史遗留的一个例外。
- 删除就是剪切：`d`、`x`、`s` 删掉的内容都进寄存器，随后 `p` 能贴回来；想纯删不留痕才用黑洞寄存器 `"_`。
- `.` 重复的是「上一次完整的修改动作」（动词+对象+输入的文字），所以批量改格式优先想：能不能做成一次可重复的修改，而不是录宏。
- 撤销是按修改步数走的链（新版 Vim 是树），在同一个 buffer 里撤销不会因为切换文件而丢失。
- 搜索和替换共用正则体系：默认是「magic」模式，`+ ? ( ) |` 这些符号要加反斜杠才有特殊含义，和常见的 PCRE 习惯正好相反。
- Ex 命令的范围默认只对当前行生效，写 `%` 才是全文；很多「替换没反应」其实是漏了范围。

### 新手易错点

- 在插入模式里按方向键到处找位置：先 `Esc` 回普通模式再移动，效率高一个量级。
- 把 `cw` 当 `dw + i` 用却发现多删了空格：`cw` 按词尾算，是特例，想精确按对象用 `ciw`。
- `yy` 复制后粘出来是刚删掉的东西：因为删除也写默认寄存器；重要内容先放命名寄存器 `"ayy`。
- 以为 `u` 撤销后保存就找不回：未开持久化撤销时确实如此，长文件编辑先存一版再大改。
- `Ctrl-v` 块选后按 `d` 只删了第一行：块操作要先选完整矩形，再用 `I` 在块首插入、用 `d` 删整块。
- 在 `:` 后面敲普通模式命令，或在普通模式敲带冒号的命令：先分清自己在哪个模式，看屏幕左下角提示。
- 搜索时忘了 `n` 是「同方向下一个」：`/` 向下搜后 `N` 是往回，别两个混着按到晕。
- 直接关终端走人：未保存内容只在 swap 和内存里，下次打开先看恢复提示，别急着删 swap。
