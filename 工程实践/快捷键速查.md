# 快捷键速查

> IDEA / VSCode / Windows。肌肉记忆清单，每晚 20:30 可增补。

## IntelliJ IDEA（Win）

| 按键 | 动作 |
|---|---|
| `Shift Shift` | 全局搜索（文件/类/符号） |
| `Ctrl+N` / `Ctrl+Shift+N` | 找类 / 找文件 |
| `Ctrl+E` | 最近打开的文件 |
| `Alt+Enter` | 万能修复（导包、生成、 quick fix） |
| `Ctrl+Alt+L` | 格式化代码 |
| `Ctrl+Alt+O` | 优化 import |
| `Shift+F6` | 重命名（重构） |
| `Ctrl+Alt+M` / `Ctrl+Alt+V` | 抽方法 / 抽变量 |
| `F8` / `F7` / `Shift+F8` | 调试：步过 / 步入 / 步出 |
| `Ctrl+F8` | 行断点开关 |
| `Alt+F8` | 调试时算表达式 |
| `Ctrl+Shift+F` | 全局文本搜索 |
| `Ctrl+Shift+R` | 全局替换 |
| `Ctrl+H` | 类继承结构 |
| `Ctrl+Q` | 快速看文档 |

## VSCode（Win）

### 导航

| 按键 | 动作 |
|---|---|
| `Ctrl+P` | 快速打开文件（输 `?` 看所有模式） |
| `Ctrl+Shift+P` | 命令面板（所有功能入口，记不住键就搜） |
| `Ctrl+T` | 全工作区符号搜索（类/方法名） |
| `Ctrl+Shift+O` | 当前文件符号搜索 |
| `F12` / `Alt+F12` | 跳到定义 / 悬浮 peek 定义 |
| `Shift+F12` | 查找所有引用 |
| `Alt+Left/Right` | 后退 / 前进（跳转历史） |
| `Ctrl+G` | 跳到指定行 |
| `Ctrl+Tab` | 最近文件切换 |

### 编辑

| 按键 | 动作 |
|---|---|
| `Alt+Up/Down` | 整行上下搬 |
| `Shift+Alt+Up/Down` | 整行复制 |
| `Ctrl+/` | 行注释开关 |
| `Shift+Alt+A` | 块注释开关 |
| `Ctrl+D` | 选中下一个相同词（多光标） |
| `Ctrl+Shift+L` | 选中所有相同词（批量改名） |
| `Alt+Click` | 任意位置加光标 |
| `Shift+Alt+拖选` | 列选择（矩形编辑） |
| `Ctrl+Shift+K` | 整行删除 |
| `Ctrl+Enter` | 下方插入空行（光标不动） |
| `Ctrl+Shift+Enter` | 上方插入空行 |

### 重构 / 调试 / 终端

| 按键 | 动作 |
|---|---|
| `F2` | 重命名符号（全项目） |
| `Ctrl+.` | 快速修复 / 重构建议（小灯泡） |
| `F5` / `Shift+F5` | 开始调试 / 停止 |
| `F9` | 打断点 |
| `F10` / `F11` | 单步跳过 / 单步进入 |
| `Ctrl+`` ` | 开关终端 |
| `Ctrl+Shift+`` ` | 新建终端 |
