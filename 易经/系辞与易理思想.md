# 系辞与易理思想

> 前置知识：本篇需要[易经/八卦与六十四卦.md](易经/八卦与六十四卦.md)的基础——八卦象征、六十四卦构成、卦辞爻辞读法。入门总纲见[易经/易经入门.md](易经/易经入门.md)。

## 1. 十翼篇目

“传”就是十翼，共十篇：

| 篇目 | 一句话作用 |
|---|---|
| 彖传上、彖传下 | 讲卦辞的大意 |
| 象传上、象传下 | 讲卦象与爻象（大象讲卦，小象讲爻） |
| 系辞传上、系辞传下 | 讲易理总纲，本篇重点 |
| 文言传 | 专讲乾坤二卦 |
| 说卦传 | 讲八卦象征 |
| 序卦传 | 讲六十四卦排列的道理 |
| 杂卦传 | 杂述各卦大义 |

传统上相传十翼为孔子所作。十翼之中，系辞传是讲易理最集中、最成体系的一篇。

## 2. 系辞核心思想

- **一阴一阳之谓道**：阴阳不是两种死物，而是事物变化的两种趋向；“道”就是阴阳往复变化的规律本身。不要把阴阳理解成两种固定不变的物质。
- **穷则变，变则通，通则久**：走到尽头就要变，变了才能通，通了才能长久。讲的是变易的积极意义，不是被动认命。
- **时与位**：同一爻在不同位置、不同时机，吉凶不同。读爻辞要先看它在第几爻（位）、处什么情境（时）。如乾卦初九“潜龙勿用”（时机未到，先潜藏）、上九“亢龙有悔”（走到极点，反而后悔），同一卦的两端爻辞截然不同，差的就是时与位。
- **中和**：中指位置适中、不过分（如九二、九五居中常得好评）；和指阴阳配合得当、不走极端。吉凶判断里，“中”常常是好信号。

## 3. 易理在后世的影响

一句话带过：易理的阴阳、变易、时位、中和观念，成为儒道思想、决策思维、中医取象类比等中国传统学问的共同文化源头。

## 4. 现代学习建议

- **先读译注本再读原文**：先懂大意，再抠字句；直接啃古文容易在字词上卡住，丢了思想。
- **不要从占卜入门**：先懂卦象与易理，占筮只是易经流传中的历史实践之一，不是理解易经的捷径。
- **阅读顺序**：[易经/易经入门.md](易经/易经入门.md) → [易经/八卦与六十四卦.md](易经/八卦与六十四卦.md) → 本篇；读完可配合一本白话译注通读六十四卦卦辞与爻辞。
- **读“吉凶”的方法**：先问在什么时、什么位、什么条件下，不要直接当成命运结论。

## 自测练习

1. 十翼是哪十篇？
2. “一阴一阳之谓道”里的“道”指什么？
3. 为什么九五常被看作好位置？

### 答案解析

1. 彖传上、下，象传上、下，系辞传上、下，文言传，说卦传，序卦传，杂卦传，共十篇。
2. 阴阳往复变化的规律本身，不是两种固定不变的物质。
3. 第五爻居上卦之中为“中”，阳爻居阳位（奇数位为阳位）为“正”，得中得正，所以常得好评。
