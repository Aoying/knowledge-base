# 图算法深篇

Dijkstra、拓扑排序、最小生成树三个深篇合集。主篇 [数据结构与算法](计算机基础/数据结构与算法.md) 只给了提纲，本篇把正确性条件、worked 例子、易错点讲透。

## 图的存法

本文代码一律用邻接表（每个节点挂一个 (邻居, 权) 列表），稀疏图省空间、遍历邻居快。邻接矩阵适合稠密图或频繁查边是否存在，本文三个算法都不需要它。

## Dijkstra：堆优化与非负权条件

思想：维护每个节点当前已知的最短距离 dist；每次从未确定的节点里取出 dist 最小的一个，它的 dist 就是最终最短（贪心）；再用它松弛所有邻居。堆优化就是用最小堆取这个最小节点。

正确性条件：边权必须非负。非负权下，后续经其他节点绕路不可能比当前最小 dist 更小，“弹出即最短”才成立；有负权边时，已弹出节点的 dist 还可能被继续压低，算法失效。负权（无负环）用 Bellman-Ford，标准复杂度 O(VE)，本文不展开。

worked 例子（有向图，A 为起点）：

```
A -> B 4, A -> C 2
B -> C 1, B -> D 5, B -> E 3
C -> B 1, C -> D 8, C -> E 10
D -> E 2
```

逐步求解：

| 弹出的节点 | 弹出的 dist | 松弛后 dist 变化 |
|---|---|---|
| A | 0 | B = 4，C = 2 |
| C | 2 | B = min(4, 2+1) = 3，D = 10，E = 12 |
| B | 3 | D = min(10, 3+5) = 8，E = min(12, 3+3) = 6 |
| E | 6 | 无出边 |
| D | 8 | E = min(6, 8+2) = 6，不变 |

最终：A = 0，B = 3，C = 2，D = 8，E = 6。

```python
import heapq

def dijkstra(graph, start):
    dist = {n: float("inf") for n in graph}
    dist[start] = 0
    pq = [(0, start)]
    while pq:
        d, u = heapq.heappop(pq)
        if d != dist[u]:  # 过期堆项，跳过
            continue
        for v, w in graph[u]:
            nd = d + w
            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(pq, (nd, v))
    return dist

g = {"A": [("B", 4), ("C", 2)], "B": [("C", 1), ("D", 5), ("E", 3)],
     "C": [("B", 1), ("D", 8), ("E", 10)], "D": [("E", 2)], "E": []}
print(dijkstra(g, "A"))  # {'A': 0, 'B': 3, 'C': 2, 'D': 8, 'E': 6}
```

堆优化标准复杂度 O((V + E) log V)。易错点：不写 `d != dist[u]` 的过期判断时，同一节点会以旧 dist 重复松弛，结果虽对但会变慢；更常见的是忘记这行导致逻辑混乱。

## 拓扑排序：Kahn 算法与环检测

思想：算每个节点的入度；把入度为 0 的节点排进队列；每次弹出一个放入结果，它的邻居入度减 1，减到 0 就进队列。

worked 例子：节点 0..4，边为 0->1、0->2、1->3、2->3、3->4。

- 初始入度：[0, 1, 1, 2, 1]，队列 [0]。
- 弹 0：1、2 入度归 0，队列 [1, 2]。
- 弹 1：3 入度 2 -> 1。
- 弹 2：3 入度 1 -> 0，队列 [3]。
- 弹 3：4 入度归 0，队列 [4]。
- 弹 4：结束。顺序为 0, 1, 2, 3, 4。

环检测：Kahn 结束时，若输出长度 < 节点数，说明剩余节点的入度永远消不掉，图中一定有环。例如上面加一条边 4->1 后，Kahn 只输出 [0, 2]，长度 2 < 5，判环。

```python
from collections import deque

def kahn(n, edges):
    indeg = [0] * n
    adj = [[] for _ in range(n)]
    for u, v in edges:
        adj[u].append(v)
        indeg[v] += 1
    q = deque([i for i in range(n) if indeg[i] == 0])
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v in adj[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return order

print(kahn(5, [(0, 1), (0, 2), (1, 3), (2, 3), (3, 4)]))  # [0, 1, 2, 3, 4]
```

标准复杂度 O(V + E)。注意拓扑序不唯一：队列里同时有多个零入度节点时，先弹谁都合法。

## 最小生成树：Kruskal + 并查集为主

思想：所有边按权从小到大试；当前边的两端若已在同一连通块，加它必成环，跳过；否则加入一定是安全的（最小横切边必在某棵最小生成树中）。并查集负责“是否同一连通块”的判断。

worked 例子（节点 A、B、C、D、E）：

| 边（按权排序） | 处理 | 原因 |
|---|---|---|
| A-B 1 | 加入 | |
| B-C 2 | 加入 | |
| A-C 3 | 跳过 | A、B、C 已连通，成环 |
| C-D 4 | 加入 | |
| B-D 5 | 跳过 | B、C、D 已连通，成环 |
| D-E 6 | 加入 | |
| C-E 7 | 跳过 | 已全部连通，成环 |

最小生成树边为 A-B、B-C、C-D、D-E，权和 = 1 + 2 + 4 + 6 = 13。

```python
class DSU:
    def __init__(self, n):
        self.p = list(range(n))
    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x
    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return False
        self.p[ra] = rb
        return True

def kruskal(n, edges):
    total, mst = 0, []
    dsu = DSU(n)
    for u, v, w in sorted(edges, key=lambda e: e[2]):
        if dsu.union(u, v):
            total += w
            mst.append((u, v, w))
    return total, mst

print(kruskal(5, [(0, 1, 1), (1, 2, 2), (0, 2, 3), (2, 3, 4),
                  (1, 3, 5), (3, 4, 6), (2, 4, 7)]))
# (13, [(0, 1, 1), (1, 2, 2), (2, 3, 4), (3, 4, 6)])
```

标准复杂度 O(E log E)，主要花在边排序上；并查集带路径压缩后每次操作接近常数。

Prim 简述：从任一节点出发，每次把横切边（已选集合与未选集合之间）中最小的一条加入，直到全部节点入选。堆优化标准复杂度 O(E log V)，稠密图可用 O(V²) 版。Kruskal 按边处理适合稀疏图，Prim 按点扩张适合稠密图。

## 易错点

- Dijkstra：忘记跳过过期堆项；对负权图直接套用。
- 拓扑排序：输出长度 < 节点数就是有环，不要硬凑顺序；多源头时零入度队列初始不止一个是正常的。
- Kruskal：边排序后必须用并查集判环，不能只看权大小；相等权重的边取舍不影响总权和，但会影响生成树的形状。

## 面试与自测

1. Dijkstra 为什么要求边权非负？有负权时用什么？
2. Kahn 算法怎样判断有环？它和 DFS 三色法各有什么特点？
3. Kruskal 为什么按权排序后用并查集判环就行？Prim 和 Kruskal 各适合什么图？

### 参考答案

1. 正确性依赖“从堆里弹出的节点 dist 已是最终最短”；非负权下，后续经其他节点绕路不可能更小，结论成立；负权边能让已弹出节点的 dist 继续变小，结论失效。负权（无负环）用 Bellman-Ford，标准复杂度 O(VE)。
2. Kahn 结束时输出长度 < 节点数，说明剩余节点入度永远消不掉，图中有环。Kahn 直观且自带环检测，还能顺手得到一组合法顺序；DFS 三色法在递归中遇到灰色节点即判环，适合顺带输出深度优先的拓扑序。
3. 边权从小到大试，当前边两端若已连通则加它必成环，跳过；否则加入一定是安全的（最小横切边必在某棵最小生成树中）。Kruskal 按边处理，适合稀疏图（O(E log E) 主要花在排序）；Prim 按点扩张，稠密图用 O(V²) 版也有优势。
