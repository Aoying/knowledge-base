# 假设检验深篇

> 本篇是[计算机基础/统计/统计推断与应用.md](计算机基础/统计/统计推断与应用.md) §4.7、§4.8 的深篇。
> §4.7 的完整流程案例（改版前后日均使用时长 50 分钟→52 分钟，z = 1.0，p ≈ 0.32）、
> §4.8 的两类错误与功效对照表、§4.6 的置信区间只作指回，本篇不再重复。
> 流程口诀先记住：立假设 → 选统计量 → 算 p 值 → 按事先定的 α 下结论。顺序不能乱，α 不能事后改。

## 1. 四种检验总览：数据结构决定用哪个

| 检验 | 场景 | 例子 |
|---|---|---|
| 单样本检验 | 一组数据，跟一个固定标准比 | 奶茶容量跟 500ml 宣称比 |
| 双样本检验 | 两批不同的人（或物），比两组均值 | A 教学法班 vs B 教学法班 |
| 配对检验 | 同一批人，前后测两次，比差值 | 同 20 人减肥前后的体重 |
| 比例检验 | 成功率、合格率、转化率，比比例 | 合格率跟 95% 标准比；两组转化率比 |

- 选择方法：先问“数据是怎么来的”。同一批人两次测量 → 配对；两批不同的人 → 双样本；跟固定数比 → 单样本；比的是百分比 → 比例检验。选错检验比算错数更严重：配对数据当双样本算，功效直接打折（见第 4 节）。
- 多组比较不用连做 t 检验：三组以上比均值用[计算机基础/统计/方差分析.md](计算机基础/统计/方差分析.md)，连做 t 检验会让整体假阳性失控（3 组连做 3 次至少错一次约 14.3%）。

## 2. 单样本 t 检验：跟固定标准比

- 一句话理解：单样本检验回答“一组数据的均值，跟某个固定值有没有显著差别”。
- 生活案例：奶茶店宣称每杯 500ml。抽 25 杯，样本均值 495ml，样本标准差 s = 10ml。宣称可信吗？
- z 与 t 的分界：总体标准差 σ 已知 → 用 z；σ 未知（常见情况，用 s 代替）且样本小 → 用 t。t 分布比正态尾巴更厚——因为 s 本身也是估计出来的，多了一层不确定性；样本量大时 t 逼近 z，差别可忽略。
- 逐步代入：原假设 H0：总体均值 = 500ml；备择 H1：总体均值 ≠ 500ml（双侧）。
  - 标准误 SE = s / √n = 10 / √25 = 10 / 5 = 2。
  - t = (495 − 500) / 2 = −2.5，自由度 df = n − 1 = 24。
  - 查 t 分布表：|t| = 2.5、df = 24 时双侧 p 值约 0.0197 < 0.05，拒绝 H0。
  - 结论规范措辞：“在 0.05 水平上拒绝原假设，有统计学证据表明平均容量不等于 500ml。”不能写成“容量不足的概率是 98%”——p 值不是原假设为真的概率（§4.7 铁律）。

## 3. 双样本 t 检验：两批不同的人

- 一句话理解：双样本检验回答“两组均值差，是不是抽样抖动能解释的”。
- 生活案例：A 教学法班 n = 30 人，均值 78 分，标准差 s = 8；B 教学法班 n = 30 人，均值 82 分，标准差 s = 9。B 法真的更好吗？
- 逐步代入（Welch 检验，不假设两组方差相等）：
  - 差值的标准误 SE = √(8²/30 + 9²/30) = √(64/30 + 81/30) = √4.833 ≈ 2.198。
  - t = (82 − 78) / 2.198 ≈ 1.82，Welch 自由度约 57.2，双侧 p 值约 0.074 > 0.05，不拒绝 H0。
  - 结论规范措辞：“在 0.05 水平上没有足够证据说两组均值不同。”注意：不是“证明两法没差别”——4 分的差距配上这个样本量，检验根本分辨不出来；要分辨，要么加样本，要么接受测不出来。
- Welch 与 Student 的选择：Student 检验假设两组方差相等，方差不等时结论会偏；Welch 不做这个假设，方差相等时结论与 Student 几乎一样。默认用 Welch，是更稳健的选择。

## 4. 配对 t 检验：同一批人前后测

- 一句话理解：配对检验不直接比两组均值，而是先算每个人前后两次的差值，再检验“差值的均值是不是 0”。
- 生活案例：20 人参加减肥计划，记录每人前后体重，差值（前 − 后）的均值 d̄ = 2.5kg，差值的标准差 s_d = 4kg。减肥有效果吗？
- 逐步代入：原假设 H0：差值总体均值 = 0（没效果）。
  - 标准误 SE = s_d / √n = 4 / √20 ≈ 0.894。
  - t = 2.5 / 0.894 ≈ 2.795，自由度 df = 19，双侧 p 值约 0.0115 < 0.05，拒绝 H0。
  - 结论：平均减重约 2.5kg，且在 0.05 水平上显著——但“显著”只说不是抖动，2.5kg 值不值得另当别论（显著 ≠ 重要，见第 7 节）。
- 为什么配对功效更高：配对把每个人当自己的对照，个体间基线差异（有人本来就重、有人本来就轻）在算差值时被消掉了，差值的标准差远小于原始体重的标准差，标准误更小，同样的效应更容易显著。同一批数据如果当成两批不同的人算双样本检验，很可能就不显著了——不是数据变了，是方法浪费了信息。

## 5. 比例检验：成功率、合格率、转化率

- 单比例检验：生活案例：工厂宣称合格率 95%。抽 200 件，合格 184 件（92%）。宣称可信吗？
  - 逐步代入：原假设 H0：总体合格率 = 0.95。标准误（按 H0 算）= √(0.95 × 0.05 / 200) = √0.0002375 ≈ 0.01541。z = (0.92 − 0.95) / 0.01541 ≈ −1.947，双侧 p 值约 0.0516。
  - 结论：p = 0.0516 略大于 0.05，不拒绝 H0——但这是一个边缘结果。规范措辞是“在 0.05 水平上没有足够证据说合格率不等于 95%”，既不能说“合格率没问题”，也不能说“有问题”。边缘结果的正确做法是加样本再看，而不是把 0.0516 说成“差一点就显著”（0.0516 和 0.049 没有本质区别，0.05 是人为划的线）。
- 双比例检验：两组转化率比较就是 A/B 测试的判定，完整流程（分流、样本量、置信区间、SRM）见[计算机基础/统计/AB测试实战.md](计算机基础/统计/AB测试实战.md)第 3 节，本篇不再重复算式。

## 6. 功效与样本量：检验前先算够不够

- 功效先说清：功效 = 1 − β，真实有效果时能发现它的概率（§4.8 指回）。检验前算样本量，就是保证功效不至于太低——否则实验还没做，结局就已经注定是“测不出来”。
- 影响功效的四样东西：真实效应越大、样本量越大、数据方差越小、α 放得越宽，功效越高。α 和 β 此消彼长（§4.8 已讲），不能既要 α 极小又要功效极高，除非加样本。
- 公式拆解（单样本均值检验，每组样本量 n）：n = [(z_{α/2} + z_β)·σ / Δ]²。其中 Δ 是想测出的均值差，σ 是总体标准差，z_{α/2} = 1.96（α = 0.05 双侧），z_β = 0.84（功效 80%）或 1.28（功效 90%）。
- 逐步代入（沿用 §4.7 的改版案例量级：σ = 20 分钟）：
  - 想测出 Δ = 5 分钟、功效 80%：n = [(1.96 + 0.84) × 20 / 5]² = (2.8 × 4)² = 11.2² = 125.44，向上取整 126 人。
  - 想测出 Δ = 2 分钟、功效 80%：n = [(1.96 + 0.84) × 20 / 2]² = (2.8 × 10)² = 28² = 784 人。效应从 5 分钟缩到 2 分钟（2.5 倍），样本量变成 784 / 125.44 = 6.25 倍——平方关系。
  - 功效提到 90%（z_β = 1.28）、Δ = 5 分钟：n = [(1.96 + 1.28) × 20 / 5]² = (3.24 × 4)² = 12.96² = 167.96，向上取整 168 人。
- 与抽样篇公式的区别：[计算机基础/统计/抽样方法与样本量.md](计算机基础/统计/抽样方法与样本量.md)的 n = (zσ/E)² 回答“估计均值要多准”，本节公式回答“检验均值差要多大把握”。一个讲估计精度，一个讲检验功效，目的不同不要混用。
- Python 复现（实跑结果与正文一致）：

```python
import math
# 配对 t（第 4 节）
se = 4 / math.sqrt(20); t = 2.5 / se
print(round(se, 3), round(t, 3))  # 0.894 2.795
# 均值检验样本量（第 6 节）
def mean_n(sigma, delta, za=1.96, zb=0.84):
    return ((za + zb) * sigma / delta) ** 2
print(math.ceil(mean_n(20, 5)))  # 126
print(math.ceil(mean_n(20, 2)))  # 784
```

## 7. p 值与置信区间的对照读法

- 对偶关系（双侧检验）：α = 0.05 的检验拒绝 H0，当且仅当 95% 置信区间不含 H0 的值。两者是同一枚硬币的两面——p 值说“有多反常”，区间说“效应可能在什么范围”。
- 对照读法（用第 4 节配对案例）：差值均值 2.5kg，标准误 0.894，t 临界值（df = 19，双侧 0.05）约 2.093。95% 置信区间 = 2.5 ± 2.093 × 0.894 = 2.5 ± 1.87，即 [0.63, 4.37]kg。
  - 与 p 值对照：区间不含 0，与 p ≈ 0.0115 < 0.05 的结论一致。
  - 区间多给的信息：p 值只说“不是 0”，区间说“平均减重可能在 0.63kg 到 4.37kg 之间”——效应大小的范围，p 值永远给不了。区间越宽，估计越不准；区间下限 0.63kg 说明即使按最保守估计，平均减重也超过 0.6kg。
- 两条禁读（§4.6、§4.7 已讲，这里再钉一次）：p 值不是“原假设为真的概率”；置信区间不是“真值有 95% 的概率落在这个区间里”（真值固定，随机的是区间本身；正确说法是“这种方法构造的区间，长期约 95% 会覆盖真值”）。
- 显著 ≠ 重要：样本量极大时，0.1kg 的平均减重也能显著，但业务上毫无意义；判断价值要看效应大小（区间位置）和业务意义，不是 p 值大小。


## 公式精讲与练习：t 统计量、p 值判读与功效

### 1. t 统计量通式：估计值离假设值几个标准误

**公式**：t =（估计值 − 假设值）/ SE。z 检验是同一公式在 σ 已知时的版本；σ 未知、用 s 代替且样本小时，统计量服从 t 分布而不是正态分布。

**符号逐项解释**：

| 符号 | 含义 |
|---|---|
| 估计值 | 样本算出的量：单样本是样本均值 x̄，配对是差值均值 d̄，比例检验是样本比例 p̂ |
| 假设值 | H0 规定的值：单样本是固定标准 μ0，配对是 0，比例检验是 p0 |
| SE | 估计值的标准误，估计量的抖动（不是数据的散布） |
| df | 自由度，t 分布的形状参数：单样本与配对是 n − 1，双样本 Welch 是近似自由度 |

**四种检验的 SE 形式对照**：

| 检验 | SE 的算式 | 自由度 |
|---|---|---|
| 单样本 t | s / √n | n − 1 |
| 双样本 Welch t | √(s1²/n1 + s2²/n2) | Welch 近似公式（软件给，不必手算） |
| 配对 t | s_d / √n（s_d 是差值的标准差） | n − 1 |
| 单比例 z | √[p0(1 − p0)/n]（按 H0 的 p0 算，不是样本比例） | 不用 t，用 z |

**逐步计算（生活案例：某电池厂宣称续航 12 小时，抽 16 块，样本均值 x̄ = 11.4 小时，样本标准差 s = 1.2 小时）**：

- 第一步，立假设：H0：总体均值 = 12 小时；H1：总体均值 ≠ 12 小时（双侧）。
- 第二步，SE = 1.2 / √16 = 1.2 / 4 = 0.3 小时。
- 第三步，t = (11.4 − 12) / 0.3 = −2.0，df = 16 − 1 = 15。含义：样本均值比宣称低了 2 个标准误。
- 第四步，双侧 0.05 的 t 临界值（df = 15）约 2.131，|t| = 2.0 < 2.131，不拒绝 H0；双侧 p 值约 0.064 > 0.05，与临界值结论一致。
- 规范措辞：“在 0.05 水平上没有足够证据说平均续航不等于 12 小时。”不是“证明了续航就是 12 小时”——16 块样本的检验根本分辨不出 0.6 小时的差距。

**直观图示（t 临界值随自由度的变化，双侧 0.05）**：

| 自由度 df | 双侧 0.05 临界值 | 直观含义 |
|---|---|---|
| 5 | 2.571 | 样本很小，s 本身很不准，门槛要放得很宽 |
| 15 | 2.131 | 上例的位置 |
| 30 | 2.042 | 已接近正态 |
| ∞（大样本） | 1.96 | t 分布退化为正态分布，与 z 的门槛相同 |

规律：df 越小，t 分布尾巴越厚，临界值越大——因为 s 是估计出来的，多了一层不确定性；df 增大时 t 逼近 z，差别可忽略（§2 已讲，这里是数值版）。

### 2. p 值判读三步：先算统计量，再看尾部面积，最后与 α 比

**定义（红线表述，只用这一种）**：p 值 = 在原假设成立的前提下，观察到当前或更极端数据的概率。它不是原假设为真的概率，不是结论正确的概率，也不是效应大小的度量。

**判读三步**：

1. 算统计量：按上一节的通式算出 t 或 z。
2. 查尾部面积：双侧检验看两边尾部面积之和（|统计量| 之外的部分）；单侧只看事先定好的那一边。方向必须事先定，看完数据再选单侧等于作弊（§7 已讲）。
3. 与事先定的 α 比：p < α 拒绝 H0，p ≥ α 不拒绝。α 不能事后改。

**常用表述口径（分档只是习惯，不是自然法则）**：

| p 值范围 | 规范表述 | 提醒 |
|---|---|---|
| p < 0.01 | 在 0.01 水平上也显著，数据相当反常 | 仍不等于“原假设只有 1% 可能为真” |
| 0.01 ≤ p < 0.05 | 在 0.05 水平上显著 | 只说“不是抖动”，效应大小另看区间 |
| 0.05 ≤ p < 0.10 | 不显著，但接近门槛 | 边缘结果：加样本再看，不要改口径 |
| p ≥ 0.10 | 没有足够证据 | 不是“证明没差别” |

**逐步计算（生活案例：某 APP 改版后转化率，H0 规定的旧转化率 p0 = 10%，抽 400 人，观测转化率 13%）**：

- 第一步，SE = √[0.10 × 0.90 / 400] = √0.000225 = 0.015。注意：按 H0 的 p0 算，不是按观测的 13% 算。
- 第二步，z = (0.13 − 0.10) / 0.015 = 2.0，双侧 p 值约 0.046 < 0.05，拒绝 H0。
- 第三步，规范措辞：“在 0.05 水平上拒绝原假设，有统计学证据表明转化率不等于 10%。”补充一句才完整：3 个百分点的提升值不值得另当别论——p 值只说“不是抖动”，效应大小与业务价值要单独判断（显著 ≠ 重要）。

### 3. 功效与样本量：检验前先算够不够

**公式（单样本均值检验，每组样本量 n）**：n = [(z_{α/2} + z_β) · σ / Δ]²。

**符号逐项解释**：

| 符号 | 含义 |
|---|---|
| Δ | 想测出的均值差，事先定的最小有意义效应，不是事后观测到的差 |
| σ | 总体标准差（或可靠估计），数据本身的散布 |
| z_{α/2} | α 对应的双侧分位数：α = 0.05 双侧时 1.96 |
| z_β | 功效对应的分位数：功效 80% 时 0.84，功效 90% 时 1.28 |
| n | 算出的样本量，永远向上取整 |

**逐步计算（沿用 §6 的改版时长量级：σ = 20 分钟，α = 0.05 双侧，功效 80%，即 z_{α/2} + z_β = 1.96 + 0.84 = 2.8）**：

- 想测出 Δ = 10 分钟：n = (2.8 × 20 / 10)² = 5.6² = 31.36，向上取整 32 人。
- 想测出 Δ = 4 分钟：n = (2.8 × 20 / 4)² = 14² = 196 人。
- 对比：效应从 10 分钟缩到 4 分钟（0.4 倍），样本量从 32 变到 196，约 6.25 倍——平方关系（(1/0.4)² = 6.25，取整后 196/32 ≈ 6.13，差异来自取整）。
- 功效提到 90%（z_β = 1.28）时 Δ = 10 分钟：n = (3.24 × 20 / 10)² = 6.48² = 41.99，向上取整 42 人。功效从 80% 提 10 个点，样本量从 32 涨到 42。

**直观图示（功效的影响因素，单调关系）**：

| 因素变化 | 功效变化 | 直观原因 |
|---|---|---|
| 真实效应 Δ 变大 | 功效 ↑ | 信号变强，更容易从抖动里分辨出来 |
| 样本量 n 变大 | 功效 ↑ | SE 变小，抖动带变窄 |
| 数据方差 σ 变小 | 功效 ↑ | 抖动本身变小 |
| α 放得越宽 | 功效 ↑ | 门槛变松，更容易拒绝——但假阳性也多了 |

底线：α 和 β 此消彼长，不能既要 α 极小又要功效极高，除非加样本。检验前不算样本量，等于没做实验就先注定了“测不出来”。

### 练习题

1. 某零件标准长度 50mm。抽 26 件，样本均值 x̄ = 49.2mm，样本标准差 s = 2.5mm，双侧 α = 0.05。求标准误 SE、t 值、自由度，并判断是否拒绝 H0。
2. 10 人参加某训练，前后分数差值（后 − 前）的均值 d̄ = 3.0 分，差值的标准差 s_d = 4.0 分，双侧 α = 0.05。求标准误 SE、t 值、自由度，判断是否拒绝 H0，并写一句效应说明（显著是否等于重要）。
3. 某店铺宣称好评率 90%。抽 100 单，好评 84 单，双侧 α = 0.05。求标准误 SE、z 值、双侧 p 值，并判断是否拒绝 H0。
4. 总体标准差 σ = 20 分钟，α = 0.05 双侧、功效 80%，想测出 10 分钟的均值差需要多少样本？想测出 4 分钟呢？效应缩到原来的 0.4 倍，样本量变几倍？符合什么关系？

### 参考答案

1. SE = 2.5 / √26 ≈ 2.5 / 5.099 ≈ 0.49mm。t = (49.2 − 50) / 0.49 ≈ −1.63，自由度 df = 26 − 1 = 25。双侧 0.05 的 t 临界值（df = 25）约 2.060，|t| = 1.63 < 2.060，不拒绝 H0；双侧 p 值约 0.12 > 0.05，与临界值结论一致。规范措辞：“在 0.05 水平上没有足够证据说平均长度不等于 50mm。”
2. SE = 4.0 / √10 ≈ 4.0 / 3.162 ≈ 1.26 分。t = 3.0 / 1.26 ≈ 2.37，自由度 df = 10 − 1 = 9。双侧 0.05 的 t 临界值（df = 9）约 2.262，|t| = 2.37 > 2.262，拒绝 H0；双侧 p 值约 0.042 < 0.05。效应说明：平均提高约 3.0 分，且在 0.05 水平上显著——但“显著”只说不是抽样抖动，3 分值不值得另当别论（显著 ≠ 重要）。
3. 按 H0 的 p0 = 0.90 算标准误：SE = √[0.90 × 0.10 / 100] = √0.0009 = 0.03。z = (0.84 − 0.90) / 0.03 = −2.0，双侧 p 值约 0.046 < 0.05，拒绝 H0。规范措辞：“在 0.05 水平上拒绝原假设，有统计学证据表明好评率不等于 90%。”
4. 测 10 分钟：n = [(1.96 + 0.84) × 20 / 10]² = 5.6² = 31.36，向上取整 32 人。测 4 分钟：n = [(1.96 + 0.84) × 20 / 4]² = 14² = 196 人。效应缩到 0.4 倍，样本量约变 6.25 倍（取整后 196/32 ≈ 6.13），符合平方关系：n 与 Δ² 成反比。

## 易混淆对比表

| 容易混淆的一对 | 区别 | 一句话记忆 |
|---|---|---|
| z 检验 vs t 检验 | σ 已知用 z；σ 未知小样本用 t（尾巴更厚）；大样本时 t 逼近 z | 已知用 z，未知小样本用 t |
| 配对 vs 双样本 | 配对是同一批人前后测、算差值；双样本是两批不同的人 | 同批人用配对，不同人用双样本 |
| 单侧 vs 双侧 | 单侧只看一个方向、功效更高；双侧看两个方向。方向必须事先定，看完数据再选单侧等于作弊 | 方向事先定，事后改是作弊 |
| p 值 vs 效应大小 | p 值讲反常程度；效应大小讲差了多少（区间位置） | p 值讲是不是，效应讲有多少 |
| 显著 vs 重要 | 显著是统计判断（不是抖动）；重要是业务判断（值不值得） | 显著不等于重要 |
| 功效 vs 置信水平 | 功效是真实有效时能发现的概率（1 − β）；置信水平是区间方法长期覆盖率（1 − α） | 一个讲发现能力，一个讲覆盖能力 |

## 常见误区

- 不显著 = 证明没差别：错。不显著只说明“现有样本量下分辨不出来”，可能是样本不够、方差太大；证明没差别需要等效性检验，不是 p > 0.05。
- p = 0.051 就说“差一点显著”：错。0.0516 和 0.049 没有本质区别，0.05 是人为划的线；边缘结果加样本再看，不要改口径。
- 看完数据选单侧：错。方向必须事先定；数据往哪边偏就选哪边单侧，假阳性直接翻倍。
- 多组连做 t 检验：错。三组以上用方差分析；连做 t 检验整体假阳性失控（见第 1 节）。
- 大样本下微小差距显著就当重要：错。样本量极大时 0.1 个点的差距也能显著，判断价值看效应大小和业务意义。

## 小技巧与冷知识

【小技巧】报告检验结果时，p 值、效应量、置信区间三件套一起给：p 值只回答“是不是抽样抖动”，Cohen's d（单样本是 (x̄ − μ0)/s）回答“差了几个标准差”，区间回答“差值可能在什么范围”。只报一个 p = 0.03 的报告，读者既不知道效应多大、也不知道方向是否稳定，等于只交了一半答案。

【小技巧】Cohen's d 有约定俗成的三档：0.2 左右算小效应、0.5 左右算中等、0.8 左右算大效应，这是 Jacob Cohen 在 1988 年《Statistical Power Analysis for the Behavioral Sciences》里提出的经验标尺。注意它只是标尺不是判决——0.2 的效应在医学里可能救命，在别处可能毫无意义，大小最终要由业务判断。

【小技巧】t 临界值可以速记三个数：自由度 30 时约 2.04，自由度 60 时约 2.00，样本很大时直接用正态的 1.96。手算或面试口算时，先按自由度落在哪个档位取近似值，再决定 |t| 过没过门槛，不用每次都翻表。

【小技巧】配对检验要检查的是“差值”的正态性，不是前后两组各自的正态性：差值服从正态分布，配对 t 检验的前提就成立，哪怕前后两组各自的分布都偏态。小样本时看差值的直方图或 Q-Q 图；差值严重偏态或有极端值时，改用 Wilcoxon 符号秩检验（1945 年提出）而不是硬套 t 检验。

【小技巧】样本量公式里的 σ 千万别拍脑袋：σ 是用历史数据或小试点估计出来的，σ 估小了，算出的样本量就不够，实验做到一半才发现功效不足。保守做法是取偏大的 σ，或者先跑一个小试点专门估计 σ，再按估计值正式算样本量。

【小技巧】p 值刚过 0.05 就“再加一点样本看看”是最常见的作弊：边看结果边决定要不要加样本，名义上的 α = 0.05 就失效了，真实假阳性率会被抬高。样本量要事先按功效算定并执行到底；确实需要中途看结果时，要用成组序贯设计并事先分配 α，而不是看一眼再决定。

【小技巧】事后算功效等于把 p 值换个说法：观测到的效应算出来的“事后功效”是 p 值的单调函数（Hoenig 与 Heisey 2001 年指出过这个问题），p 值大时事后功效必然低，算它得不到任何新信息。功效只能在实验前用“事先定的最小有意义效应”算，实验后再算功效是循环论证。

【小技巧】同时检验多个指标或多组时，先做多重比较校正再下结论：最简单的是 Bonferroni 校正，把 α 除以检验次数 m 再逐个比。不校正时至少错一次的概率是 1 − (1 − α)^m，α = 0.05、m = 10 时约 40%——十个指标里不校正就敢报“显著”，几乎是每两次实验就错一次。

【小技巧】比例检验前先看正态近似够不够用：经验规则是 np₀ ≥ 10 且 n(1 − p₀) ≥ 10（p₀ 是 H0 规定的比例）。样本小或比例接近 0、1 时，正态近似会失真，改用精确二项检验，别硬套 z 公式。

【小技巧】“不显著”想下“没差别”的结论，要用等效性检验而不是 p > 0.05：标准做法是 TOST（双单侧检验，Schuirmann 1987 年提出），事先定一个“小到可以忽略”的等效界，先后两次单侧检验都通过，才算证明了等效。p > 0.05 只说明“分辨不出来”，等效性检验才回答“确实差不多”。

【小技巧】功效分析里想测的 Δ 要事先定“最小有意义效应”，不是事后拿观测到的差往公式里套：观测到的差本身带抽样抖动，用它反推“需要多少样本”会系统性地低估样本量。Δ 的正确来源是业务判断——差多少才值得行动，事先写下来，再去算 n。

【冷知识】t 分布的“Student”是个笔名：提出者 William Sealy Gosset 是吉尼斯酿酒厂的统计师，1908 年发表《The Probable Error of a Mean》时因公司不许员工发表论文，只能用 Student 这个化名。t 检验一出生就是为小样本质量控制服务的，酿酒厂每天只能抽几杯酒化验，大样本理论根本用不上。

【冷知识】0.05 这个门槛是 Fisher 在 1925 年《Statistical Methods for Research Workers》里随手定的：他写道 p = 0.05 是个“方便”的标准，既不是从数学里推导出来的，也不是自然法则。p 值是 Fisher 的体系，而 α、β、功效这套决策框架是 Neyman 与 Pearson 在 1933 年的论文里建立的——今天课本里混用的两套东西，原本是两个学派。

【冷知识】美国统计协会（ASA）在 2016 年专门为 p 值发过一份声明：《The ASA Statement on p-Values》，列了六条原则，第一条就是“p 值能说明数据与特定统计模型的不一致程度，但不能说明原假设为真的概率”。这是 ASA 成立 177 年来第一次就某个具体统计方法发表正式声明，背景是 p 值被滥用得太厉害。

【冷知识】心理学在 2015 年做过一次大规模“重跑实验”：Open Science Collaboration 把 100 项已发表的心理学研究原样重做，只有 36% 重复出了显著结果。重复不出来的研究里，不少正是靠 p 值刚过 0.05、样本量偏小、多重检验不校正发表的——这场可重复性危机直接推动了预注册、功效先行和报告效应量这些规范。

【冷知识】Welch 检验比 Student 检验晚了近四十年：Student 的 t 检验是 1908 年的，Welch 在 1947 年的论文里才解决了“两组方差不等怎么办”。方差齐性这个假设被默认了几十年，Welch 之后人们才发现：方差不等时 Student 检验会偏，而 Welch 在方差相等时结论几乎一样，所以默认用 Welch 是更稳健的选择。

【冷知识】Bonferroni 校正得名于意大利数学家 Carlo Emilio Bonferroni，他在 1936 年的论文里提出了这个不等式，但他本人研究的是保险精算里的概率界，不是假设检验。后人把他的不等式借用到多重检验上，做法简单到只是“α 除以检验次数”，代价是检验次数一多就过于保守，容易把真效应也漏掉。

## 面试与自测

1. 同一批人减肥前后的体重数据，应该用配对检验还是双样本检验？为什么？
2. 配对检验算得 t = 2.795（df = 19），p ≈ 0.0115，95% 置信区间 [0.63, 4.37]kg。请同时用 p 值和置信区间下结论，并说明区间比 p 值多给了什么信息。
3. 总体标准差 σ = 20 分钟，α = 0.05 双侧、功效 80%，想测出 5 分钟的均值差需要多少样本？想测出 2 分钟呢？样本量变化符合什么关系？

### 参考答案

1. 用配对检验。同一批人前后测，个体间基线差异在算差值时被消掉了，差值的标准差远小于原始标准差，标准误更小、功效更高；当成两批不同的人算双样本检验会浪费信息，很可能本来显著的结果变得不显著。
2. p = 0.0115 < 0.05，在 0.05 水平上拒绝原假设，有统计学证据表明平均减重不为 0；95% 置信区间 [0.63, 4.37]kg 不含 0，与 p 值结论一致。区间多给的信息是效应大小的范围：平均减重可能在 0.63kg 到 4.37kg 之间，下限说明即使最保守估计也有 0.6kg 以上——p 值只说“不是 0”，给不了这个范围。
3. 测 5 分钟：n = [(1.96 + 0.84) × 20 / 5]² = 125.44，向上取整 126 人。测 2 分钟：n = [(1.96 + 0.84) × 20 / 2]² = 784 人。样本量变成 784 / 125.44 = 6.25 倍，符合平方关系（效应缩 2.5 倍，样本量变 2.5² = 6.25 倍，取整后 126 与 784 之比约 6.22，差异来自取整）。
