# 时间序列入门

> 前置知识：主篇的均值概念，进阶篇的相关系数。时间序列是“带时间顺序的数据”，顺序本身就是信息。

## 一句话理解

时间序列分析是研究“随时间变化的数据”的方法：它不把数据当成一堆无关的数，而是看趋势、季节、波动如何随时间展开，并据此预测下一步。

## 为什么需要：顺序不能打乱

奶茶店月销量、股价、气温——把这些数打乱重排，均值方差都不变，但信息全丢了：夏天卖得多、冬天卖得少，恰恰藏在顺序里。普通回归假设样本相互独立，时间序列数据偏偏前后相关，硬套普通方法会低估误差、高估把握。

## 三分解：趋势、季节、残差

任何时间序列都可以拆成三部分：

- 趋势：长期的上升或下降（如奶茶店逐年越开越多，销量逐年抬升）。
- 季节：固定周期内的规律起伏（如每年暑假销量高、寒假低；每周五晚上订单多）。
- 残差：去掉趋势和季节后剩下的 irregular 波动（如某月搞促销、某天暴雨）。

看数据的第一步永远是先画图：趋势是升是降、有没有季节性、波动幅度是否稳定，图上看完再选方法。

## 平稳性直觉

平稳是指“统计性质不随时间漂移”：均值、方差大致稳定，没有长期趋势。平稳序列可以直接套很多标准方法；不平稳的序列要先处理（最常用的是差分：用今天的值减昨天的值，差分后的序列往往就平稳了）。

## 自相关：今天与昨天有多像

自相关是序列与自身延迟版本的 correlation：滞后 1 阶自相关，就是“今天的值”与“昨天的值”之间的相关系数。接近 1 说明今天高明天大概率也高（有惯性），接近 0 说明前后没什么关系。

例：某店连续 7 天销量 20、22、21、25、24、26、28。均值 166/7 ≈ 23.71。标准算法：每天减均值得到偏差，前后两天偏差相乘再求和约 18.35，除以偏差平方和约 49.43，得滞后 1 阶自相关约 0.37：大于 0 说明今天卖得好、明天倾向于也不差，但 0.37 只是中等程度的惯性，不能只凭昨天预测明天。

## 移动平均：抹平抖动看趋势

3 日移动平均 = 每连续 3 天的均值，窗口向前滑动：

(20+22+21)/3 = 21.00；(22+21+25)/3 ≈ 22.67；(21+25+24)/3 ≈ 23.33；(25+24+26)/3 = 25.00；(24+26+28)/3 = 26.00。

原始序列 20、22、21、25、24、26、28 有上有下，移动平均 21、22.67、23.33、25、26 走出一条干净的上升趋势。窗口越大曲线越平滑，但对转折的反应也越迟钝。

## 指数平滑：越近期权重越大

指数平滑 S_t = α·x_t + (1−α)·S_{t−1}，α 在 0–1 之间：α 越大，近期数据话语权越大；α 越小，历史平均越占主导。取 α = 0.3，从 S₁ = 20 起步：

S₂ = 0.3×22 + 0.7×20 = 20.60；S₃ = 0.3×21 + 0.7×20.60 = 20.72；S₄ = 0.3×25 + 0.7×20.72 = 22.00；S₅ = 0.3×24 + 0.7×22.00 = 22.60；S₆ = 0.3×26 + 0.7×22.60 = 23.62；S₇ = 0.3×28 + 0.7×23.62 = 24.94。

下一期预测值就是最后的平滑值 24.94。指数平滑的好处是不用存全部历史：一个平滑值就浓缩了过去。

## 差分：消除趋势的常用手法

对同一序列逐项相减：2、−1、4、−1、2、2（由 20、22、21、25、24、26、28 得来）。差分后围绕 0 上下波动，原来的上升趋势被消掉了——这就是“差分让序列变平稳”的直观含义。差分一次不够时可以差分两次，但差分次数越多，噪声也会被放大。

## ARIMA 一句话定位

ARIMA 是三个部件的组合：AR（自回归：用过去 p 个值预测现在）、I（差分 d 次让序列平稳）、MA（移动平均：用过去 q 个预测误差修正现在）。记作 ARIMA(p, d, q)。选 p、d、q 需要看自相关图与偏自相关图，本篇不展开推导，知道“ARIMA = 过去值 + 差分 + 过去误差”这个结构就够了。


## 公式精讲与练习：移动平均与指数平滑

原篇讲了移动平均与指数平滑的定义，本节用同一组新数据把两种方法并排算到底：窗口怎么滑、递推式每一步怎么代、α 大小到底改变了什么。

### 生活案例：奶茶店连续 6 天销量

某奶茶店连续 6 天销量（杯）：30、34、32、38、36、42。整体向上走，但中间有上有下，正好用来看两种平滑怎么“抹抖动、露趋势”。

### 移动平均：窗口滑过去，抖动就平了

3 日移动平均 = 每连续 3 天的均值，窗口向前滑一格算一个值：

| 窗口 | 算式 | 结果 |
|---|---|---|
| 第 1–3 天 | (30+34+32)/3 | 32.00 |
| 第 2–4 天 | (34+32+38)/3 | 34.67 |
| 第 3–5 天 | (32+38+36)/3 | 35.33 |
| 第 4–6 天 | (38+36+42)/3 | 38.67 |

原始序列 30、34、32、38、36、42 有上有下，移动平均 32.00、34.67、35.33、38.67 走出一条干净的上升趋势。两个代价要同时记住：窗口内的数据被平均掉了细节（第 2 天的 34 与第 3 天的 32 在平均里不再区分），而且序列首尾会丢值——6 天数据只能算出 4 个 3 日均值，前 2 天没有对应的平滑值。

### 指数平滑：递推式里 α 是当期数据的权重

递推式 S_t = α·x_t + (1−α)·S_{t−1}，符号含义：

- x_t：第 t 期的实际值。
- S_t：第 t 期的平滑值，也是对下一期的预测值。
- S_{t−1}：上一期的平滑值，里面已经浓缩了全部历史。
- α（0–1 之间）：当期实际值的权重；α 越大，近期话语权越大。

从 S₁ = 30 起步（第一期平滑值就取第一个实际值），α = 0.3 与 α = 0.7 并排算：

| 期 | 实际值 | α = 0.3 的平滑值 | α = 0.7 的平滑值 |
|---|---|---|---|
| 1 | 30 | 30.00 | 30.00 |
| 2 | 34 | 0.3×34 + 0.7×30 = 31.20 | 0.7×34 + 0.3×30 = 32.80 |
| 3 | 32 | 0.3×32 + 0.7×31.20 = 31.44 | 0.7×32 + 0.3×32.80 = 32.24 |
| 4 | 38 | 0.3×38 + 0.7×31.44 = 33.41 | 0.7×38 + 0.3×32.24 = 36.27 |
| 5 | 36 | 0.3×36 + 0.7×33.41 = 34.19 | 0.7×36 + 0.3×36.27 = 36.08 |
| 6 | 42 | 0.3×42 + 0.7×34.19 = 36.53 | 0.7×42 + 0.3×36.08 = 40.22 |

下一期预测值就是最后的平滑值：α = 0.3 预测 36.53，α = 0.7 预测 40.22。α = 0.7 的终值更贴近最新值 42，跟近期走得更紧；α = 0.3 的终值更平滑，但对第 6 天的跳升反应更慢。

### α 的两面：权重衰减表看得最清楚

α = 0.3 时，各期历史数据对当前平滑值的权重是几何衰减的：

| 距今几期 | 0（当期） | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| 权重 | 0.300 | 0.210 | 0.147 | 0.103 | 0.072 |

这就是“指数”二字的来源：越久远的数据权重越小，但永远不归零——指数平滑不用存全部历史，一个平滑值就浓缩了过去。α 越大，衰减越快（α = 0.7 时上期权重只剩 0.21，再上期 0.063），曲线跟近期越紧，也越容易被单日噪声带偏；α 越小，曲线越稳，但转折出现时要晚几步才跟上——与移动平均“窗口越大越平滑、反应越迟钝”是同一个权衡。

### 练习题

1. 移动平均：某店 5 天销量 10、14、12、18、16，求 3 日移动平均的全部值，并说出它说明了什么。
2. 指数平滑：序列 50、52、48，α = 0.5，从 S₁ = 50 起步，求 S₂、S₃，并给出下一期预测值。
3. 差分定性：序列 5、9、13、17、21，一阶差分是多少？差分后的序列围绕 0 波动吗？这说明什么？如果差分后仍有趋势，该怎么办？
4. α 选择：促销季销量先突增后回落，短期补货预测与长期趋势判断两种用途，α 分别该取大还是取小？为什么？

### 参考答案

1. (10+14+12)/3 = 12.00；(14+12+18)/3 ≈ 14.67；(12+18+16)/3 ≈ 15.33。移动平均 12.00、14.67、15.33 一路抬升，抹掉了单日抖动，露出上升趋势；5 天数据只能算出 3 个值，首尾各丢一部分。
2. S₂ = 0.5×52 + 0.5×50 = 51；S₃ = 0.5×48 + 0.5×51 = 49.5。下一期预测值就是最后的平滑值 49.5。
3. 一阶差分：9−5 = 4、13−9 = 4、17−13 = 4、21−17 = 4，差分后恒为 4，不围绕 0 波动。这说明差分消除的是趋势本身，差分后的均值等于原趋势的平均增速（每天 +4），不是非得是 0；原篇例子差分后围绕 0，是因为那组数据的日均增速接近 0 附近波动。如果差分后仍有趋势，可以再差分一次（二次差分），但差分次数越多，噪声也会被放大。
4. 短期补货预测取较大 α：要快速跟上促销带来的转折，近期数据权重必须够大。长期趋势判断取较小 α：促销是短期扰动，小 α 能把它抹平，不让一次突增带偏趋势线。同一组数据、两种用途，α 的取法相反——先定用途，再定 α。

## 容易混淆与常见误区

- 拿时间序列当普通回归：残差自相关会让标准误被低估，p 值显得比实际更显著——把握被高估了。
- 不处理季节性就判趋势：每年暑假都高，今年暑假高不代表趋势上升，可能是季节到了。
- 外推越远越不可靠：时间序列预测是“按惯性外推”，转折点（政策变、市场变）出现时，模型不会提前知道。
- 移动平均的滞后：窗口越大越平滑，但转折出现时平滑曲线要晚几步才跟上，别拿它做实时报警。

## 实际应用

销量与库存预测、服务器负载容量规划、气温与用电量预测、金融波动观察——凡是“按时间采集、要预测下一步”的数据，先画图、看趋势季节、再选平滑或 ARIMA。

## 面试与自测

1. 某店 7 天销量 20、22、21、25、24、26、28，3 日移动平均的前两个值是多少？它说明了什么？
2. 指数平滑 α = 0.3 时，S₂ 为什么是 20.60？α 变大后近期数据话语权变大还是变小？
3. 为什么不能直接拿时间序列数据做普通回归？

### 参考答案

1. (20+22+21)/3 = 21.00，(22+21+25)/3 ≈ 22.67。移动平均抹掉了单日抖动，露出上升趋势；窗口滑动后 21、22.67、23.33、25、26 一路抬升，说明销量在趋势性走高。
2. S₂ = 0.3×22 + 0.7×20 = 6.6 + 14 = 20.60。α 是当期数据的权重，α 变大后近期数据话语权变大、曲线跟近期走得更紧，但也更容易被单日噪声带偏。
3. 因为时间序列前后相关，违反普通回归“样本独立”的假设，残差自相关会让标准误被低估、p 值虚小，把握被高估；要先处理自相关与季节性，或改用时间序列方法。
