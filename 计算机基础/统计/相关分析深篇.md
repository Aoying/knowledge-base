> 本篇是[计算机基础/统计/统计推断与应用.md](计算机基础/统计/统计推断与应用.md) §5.1 的深篇。

> [计算机基础/统计/回归分析.md](计算机基础/统计/回归分析.md)的多元与逻辑回归只作指回，本篇不再重复。
> 核心红线先立住：相关是“一起变”，因果是“一个导致另一个”——相关系数无论多高，都不能直接读出因果。

## 1. Pearson 相关系数：只量线性

- 一句话理解：Pearson r 量的是“两个变量在多大程度上沿一条直线一起变”，取值在 −1 到 1 之间。
- 公式拆解（§5.1 已讲，这里只列不推）：r = Σ[(x − x̄)(y − ȳ)] / √[Σ(x − x̄)²·Σ(y − ȳ)²]。分子是“同向偏离贡献正数、反向偏离贡献负数”，分母把结果标准化到 −1 到 1。
- 适用条件（不满足时 r 会骗人）：关系是线性的；变量是连续数值；没有极端异常值（一个离群点就能把 r 拉跑）；r 本身的显著性检验才需要正态性，算 r 这个数不需要。
- 生活案例：5 个城市某天最高气温 x = [18, 22, 25, 28, 32]（℃），冰淇淋销量 y = [120, 160, 150, 210, 260]（份）。逐步算：均值 x̄ = 25，ȳ = 180。离差乘积和 = (−7)(−60) + (−3)(−20) + 0×(−30) + 3×30 + 7×80 = 420 + 60 + 0 + 90 + 560 = 1130。Σdx² = 49 + 9 + 0 + 9 + 49 = 116，Σdy² = 3600 + 400 + 900 + 900 + 6400 = 12200。r = 1130 / √(116 × 12200) = 1130 / √1415200 ≈ 1130 / 1189.6 ≈ 0.95。
- 结果怎么理解：0.95 是很强的线性正相关——气温越高，销量倾向于越高。但这句话里没有因果：不能说“气温导致销量”，也不能说“销量导致气温”，只能说“沿直线一起变”。
- Python 复现（实跑结果与正文一致）：

```python
import math
def pearson(x, y):
    n = len(x); mx = sum(x) / n; my = sum(y) / n
    num = sum((a - mx) * (b - my) for a, b in zip(x, y))
    den = math.sqrt(sum((a - mx) ** 2 for a in x) * sum((b - my) ** 2 for b in y))
    return num / den
print(round(pearson([18, 22, 25, 28, 32], [120, 160, 150, 210, 260]), 3))  # 0.95
```

## 2. Spearman 等级相关：只看顺序，不管数值大小

- 一句话理解：Spearman ρ 是“把数值换成名次，再算 Pearson”。它量的是单调关系——一个变大、另一个倾向于变大（不要求沿直线）。
- 做法：x 按大小排成第 1、2、3……名，y 同样排成名次，然后对两组名次算 Pearson。名次只关心顺序，原始数值差 1 还是差 100 都一样。
- 适用：关系是单调但非线性；数据是顺序等级（如评分、名次）；有极端异常值（异常值再大也只占一个名次，拉不动结果）。
- 生活案例：投入 x = [1, 2, 3, 4, 5]（单位），产出 y = [2, 4, 8, 16, 32]（翻倍增长，指数关系）。Pearson ≈ 0.933（已经很高，但指数曲线的弯曲让它到不了 1）；Spearman = 1.0（x 的名次 [1, 2, 3, 4, 5] 与 y 的名次 [1, 2, 3, 4, 5] 完全一致，单调性完美）。
- 结果怎么理解：Spearman 告诉你“单调性完美”，Pearson 告诉你“线性程度 0.933”。两个数回答不同问题：想知道“是不是单调”，看 Spearman；想知道“是不是直线”，看 Pearson。

## 3. Kendall τ：数数有几对顺序一致

- 一句话理解：Kendall τ 是“任意取两对数据，顺序一致的对子比不一致的多多少”。
- 公式拆解：τ = (C − D) / [n(n − 1) / 2]。C 是一致对数（x 大的那对 y 也大），D 是不一致对数（x 大的那对 y 反而小），分母是总对数。
- 生活案例：x = [1, 2, 3, 4]，y = [1, 3, 2, 4]。6 对逐一数：(1,2) x 升 y 升，一致；(1,3) 一致；(1,4) 一致；(2,3) x 升 y 降（3→2），不一致；(2,4) 一致；(3,4) 一致。C = 5，D = 1，τ = (5 − 1) / 6 ≈ 0.667。
- 适用与注意：小样本、顺序数据时更稳健；τ 的数值通常比 Spearman 小（同一组数据 τ = 0.667 时 Spearman 可能接近 0.8），两者不直接可比，不要拿 τ 的大小去套 Pearson 的“强弱”标准。

## 4. 非线性相关：Pearson 接近 0 不等于没关系

- 生活案例：x = [−2, −1, 0, 1, 2]，y = [4, 1, 0, 1, 4]，即 y = x²（对称抛物线）。逐步算：均值 x̄ = 0，ȳ = 2。离差乘积和 = (−2)(2) + (−1)(−1) + 0×(−2) + 1×(−1) + 2×2 = −4 + 1 + 0 − 1 + 4 = 0。分子是 0，所以 Pearson r = 0.0（精确为 0，不是约等于）。
- 结果怎么理解：x 和 y 的关系强到可以写成公式 y = x²，但 Pearson 说是 0——因为它只量直线，抛物线左支的负向趋势和右支的正向趋势恰好抵消了。
- 铁律：报 r 之前先画散点图。散点图呈曲线、分组、环形时，r 的数值没有意义；这时要换模型（比如拟合曲线、分段看），而不是报一个 0 就说“没关系”。

## 5. 相关矩阵读法：多变量一起看

- 一句话理解：相关矩阵是“每两个变量之间的 r 排成一张表”，用来一眼看清多变量之间的两两关系。
- 完整例子（学习时间、睡眠时间、考试分数，均为 Pearson r）：

|  | 学习时间 | 睡眠时间 | 考试分数 |
|---|---|---|---|
| 学习时间 | 1 | −0.2 | 0.7 |
| 睡眠时间 | −0.2 | 1 | 0.5 |
| 考试分数 | 0.7 | 0.5 | 1 |

- 读法三条：对角线恒为 1（自己和自己完全相关）；矩阵对称（学习–分数和分数–学习是同一个数）；看绝对值大小和方向——学习–分数 0.7 最强（正相关），睡眠–分数 0.5 中等（正相关），学习–睡眠 −0.2 弱负相关（学得多的人睡得略少）。
- 合法性一句话：这张表不是随便填的数就能叫相关矩阵——它必须是半正定的（行列式等检验通过）。上面这张表的行列式 ≈ 0.08 > 0，合法；如果填出一张不合法的表（比如三个两两强相关却互相矛盾），后面的多元分析会直接报错或出荒谬结果。
- 不能从矩阵读出的东西：因果链（不能说“学习通过分数影响睡眠”或任何方向）；成对相关互相干扰——学习和睡眠本身相关（−0.2），它们各自与分数的相关里都混进了对方的影响，想分开看要做多元回归（[计算机基础/统计/回归分析.md](计算机基础/统计/回归分析.md) §1.3 的共线性就是这回事）。

## 6. 相关 ≠ 因果：四种可能，一个一个排除

- 相关成立时，先列出四种可能，再谈因果：
  - A 导致 B：学习时间增加，分数提高。
  - B 导致 A：分数高的学生更愿意花时间学习（反向因果）。
  - 第三变量 C 同时导致 A 和 B：自律性强的学生既学得多、分数也高；把自律性拿掉，学习–分数的相关可能大幅缩水。
  - 巧合或选择偏差：样本恰好是这么挑的，或者纯属偶然（小样本里偶然强相关很常见）。
- 生活案例（第三变量最典型）：
  - 消防员人数与火灾损失正相关：不是消防员造成了损失，是火灾规模同时决定了派多少消防员和损失多大。
  - 孩子鞋码与阅读能力正相关：不是大脚促进阅读，是年龄同时让脚变大、阅读能力变强。按年龄分组后，组内相关就消失了。
  - 冰淇淋销量与溺水数正相关：夏天高温是第三变量（[计算机基础/统计/统计推断与应用.md](计算机基础/统计/统计推断与应用.md) §5.4 已讲）。
- 因果需要什么：随机对照实验（[计算机基础/统计/AB测试实战.md](计算机基础/统计/AB测试实战.md)：随机分流保证两组可比）是最干净的证据；没有随机时，需要准实验设计（前后对照、工具变量等）并论证混杂已控制。相关系数本身永远给不了因果——它只是“值得进一步检验的假设”。


## 公式精讲与练习：Pearson 与 Spearman 手算

原篇 §1–§3 给了公式拆解和各一例，本节把两个核心公式拆开讲透：每个符号是什么意思、数字怎么一步步代入、图长什么样，再配 4 道练习题。生活案例即每小节的计算例题本身，不另堆案例（原篇已有 5 处）。

### Pearson r：分子是“同向还是反向”，分母是“标准化”

公式：r = Σ[(x − x̄)(y − ȳ)] / √[Σ(x − x̄)²·Σ(y − ȳ)²]。

| 符号 | 含义 | 手算时注意 |
|---|---|---|
| x̄、ȳ | x、y 各自的均值 | 先算均值，再算离差，不要跳步 |
| (x − x̄)(y − ȳ) | 一对数据的离差乘积 | 同向偏离（同高于或同低于均值）贡献正数，反向偏离贡献负数 |
| Σ[(x − x̄)(y − ȳ)] | 离差乘积和，即分子 | 正负抵消后剩下的就是“净同向程度” |
| √[Σ(x − x̄)²·Σ(y − ȳ)²] | 分母，把分子标准化 | 保证 r 落在 −1 到 1 之间；分母恒为正 |

生活案例（全新数字，不重复原篇）：6 名学生每天复习时长 x = [1, 2, 3, 4, 5, 6]（小时），听写得分 y = [3, 5, 4, 7, 8, 9]（满分 10 分）。逐步算：

1. 均值：x̄ = 21 / 6 = 3.5，ȳ = 36 / 6 = 6。
2. 离差与乘积（逐对列出，防算错）：

| x | y | x − x̄ | y − ȳ | (x − x̄)(y − ȳ) | (x − x̄)² | (y − ȳ)² |
|---|---|---|---|---|---|---|
| 1 | 3 | −2.5 | −3 | 7.5 | 6.25 | 9 |
| 2 | 5 | −1.5 | −1 | 1.5 | 2.25 | 1 |
| 3 | 4 | −0.5 | −2 | 1.0 | 0.25 | 4 |
| 4 | 7 | 0.5 | 1 | 0.5 | 0.25 | 1 |
| 5 | 8 | 1.5 | 2 | 3.0 | 2.25 | 4 |
| 6 | 9 | 2.5 | 3 | 7.5 | 6.25 | 9 |
| 合计 | | | | **21.0** | **17.5** | **28** |

3. 代入：r = 21 / √(17.5 × 28) = 21 / √490 ≈ 21 / 22.14 ≈ 0.949。
4. 读法：0.949 是很强的线性正相关——复习越久，听写倾向于越高。但这句话里没有因果：不能说“复习导致高分”（也可能是基础好的学生本来就复习久，即第三变量），只能说“沿直线一起变”。

图示：散点形态与 r 值对照（报 r 之前先对一下图长什么样）。

| 散点形态 | r 大致 | 读法 |
|---|---|---|
| 点基本贴在一条上升直线上 | 接近 1（如本例 0.949） | 强线性正相关 |
| 点呈上升云团，带宽较宽 | 0.3–0.7 | 中等线性正相关，个体差异大 |
| 点呈一团云，无上升下降趋势 | 接近 0 | 无线性关系（但未必没关系，见 §4） |
| 点呈 U 形、抛物线、环形 | 可能接近 0 | 有关系但非线性，r 量不出来 |
| 点基本贴在一条下降直线上 | 接近 −1 | 强线性负相关 |

### Spearman ρ：名次的 Pearson，无并列时有差分捷径

原篇 §2 定的是做法（数值换名次再算 Pearson）。无并列名次时，有一步到位的差分公式：

ρ = 1 − 6Σd² / [n(n² − 1)]

| 符号 | 含义 | 手算时注意 |
|---|---|---|
| n | 数据对数 | 与 Pearson 的 n 是同一个 |
| d | 同一对数据的 x 名次减 y 名次 | 名次按从小到大排，第 1 名最小 |
| Σd² | 名次差平方和 | 顺序完全一致时 Σd² = 0，ρ = 1；顺序完全相反时 ρ = −1 |
| 分母 n(n² − 1) | 名次差平方和的最大可能规模 | 只在无并列时成立；有并列名次时取平均秩，再回原篇做法对名次算 Pearson |

生活案例（全新数字）：某咖啡店 5 周广告投入 x = [10, 20, 30, 40, 50]（千元），订单量 y = [5, 9, 8, 14, 13]（千单）。逐步算：

1. 换名次：x 名次 [1, 2, 3, 4, 5]；y 从小到大是 5、8、9、13、14，所以 y 名次 [1, 3, 2, 5, 4]（注意第 2 周的 9 排第 3，第 3 周的 8 排第 2，顺序换了一下）。
2. 名次差：d = [0, −1, 1, −1, 1]，d² = [0, 1, 1, 1, 1]，Σd² = 4。
3. 代入：ρ = 1 − 6 × 4 / [5 × (25 − 1)] = 1 − 24 / 120 = 1 − 0.2 = 0.8。
4. 对照与读法：同一组数算 Pearson 得约 0.897（原始数值差距大，趋势主导），Spearman 得 0.8（只看顺序，第 2、3 周的一次顺序颠倒就把 ρ 拉下来 0.2）。两个数回答不同问题：想知道“是不是单调上升”，看 Spearman；想知道“沿直线贴合多紧”，看 Pearson。数值本身不直接可比，不要说“0.8 比 0.897 弱所以单调性差”。

### 练习题

1. 手算 Pearson：x = [2, 4, 6, 8]，y = [3, 7, 5, 9]。列出离差乘积表，算出 r。
2. 判断题：某研究测得两变量 Pearson r ≈ 0.02，据此报告“两者没有关系”。这个结论对吗？请用一组 U 形数据说明理由（自己给 5 对数并算出 r）。
3. 手算 Spearman：5 位选手训练时长名次 [1, 2, 3, 4, 5]，比赛名次 [2, 1, 4, 3, 5]。用差分公式算 ρ。
4. 方法选择：顾客满意度（1–5 星顺序评分）与复购次数之间想算相关，且数据里混进一个极端值（某顾客复购 200 次）。选 Pearson 还是 Spearman？为什么？

### 参考答案

1. 均值 x̄ = 5，ȳ = 6。离差乘积：(−3)(−3) = 9、(−1)(1) = −1、(1)(−1) = −1、(3)(3) = 9，合计 16。Σdx² = 9 + 1 + 1 + 9 = 20，Σdy² = 9 + 1 + 1 + 9 = 20。r = 16 / √400 = 16 / 20 = 0.8。
2. 不对。r ≈ 0 只说明没有线性关系，不等于没关系。反例：x = [1, 2, 3, 4, 5]，y = [10, 4, 2, 4, 10]（U 形）。均值 x̄ = 3，ȳ = 6；离差乘积：(−2)(4) = −8、(−1)(−2) = 2、0×(−4) = 0、(1)(−2) = −2、(2)(4) = 8，合计 0，所以 r = 0（精确为 0）。关系明明很强（两端高、中间低），Pearson 却量不出来，因为它只量直线。正确做法是先画散点图，看到 U 形就换模型，不要报一个 0 就说没关系。
3. d = [−1, 1, −1, 1, 0]，d² = [1, 1, 1, 1, 0]，Σd² = 4。ρ = 1 − 6 × 4 / [5 × 24] = 1 − 0.2 = 0.8。顺序基本一致，只换了两对名次，所以 ρ 接近 1 但不到 1。
4. 选 Spearman。两个理由：第一，星级是顺序数据，数值间距（4 星与 5 星的差）不代表真实差距，Pearson 用原始数值不合适；第二，极端值再大也只占一个名次，拉不动等级相关，而 Pearson 会被它拉跑。顺序数据、有异常值时都优先 Spearman（或 Kendall）。

## 易混淆对比表

| 容易混淆的一对 | 区别 | 一句话记忆 |
|---|---|---|
| Pearson vs Spearman | Pearson 量线性，用原始数值；Spearman 量单调，用名次 | 一个看直线，一个看顺序 |
| Spearman vs Kendall | 都量单调；Spearman 是名次的 Pearson，Kendall 是数一致对 | 一个算名次相关，一个数对子 |
| r = 0 vs 没关系 | r = 0 只说明没有线性关系；曲线关系、分组关系都可能 r = 0 | 0 是“没直线”，不是“没关系” |
| 相关强 vs 因果 | 相关强只说明一起变；因果需要随机对照或排除混杂 | 一起变不等于谁导致谁 |
| 相关矩阵 vs 因果图 | 相关矩阵是对称的两两相关；因果图是有方向的假设 | 矩阵无方向，因果图有箭头 |

## 常见误区

- r 高就说因果：错。先过第 6 节的四种可能，尤其先找第三变量。
- r = 0 就说没关系：错。抛物线、分组、环形数据都可能 r = 0；先画散点图。
- 不看散点图直接报 r：错。异常值、分组、曲线都会让 r 失真，图是一切的前提。
- 用 Pearson 算顺序数据：错。评分、名次这类顺序数据用 Spearman 或 Kendall，不用 Pearson。
- 相关矩阵数值互相攀比：错。不同对子的 r 来自不同变量对，τ 和 Spearman 的数值标尺还不一样，不能跨方法比大小。
- 对角线不是 1 就当没事：错。相关矩阵对角线恒为 1，对不上说明表本身算错了。

## 面试与自测

1. x = [−2, −1, 0, 1, 2]，y = [4, 1, 0, 1, 4]（y = x²），Pearson r 是多少？这说明 x 和 y 没关系吗？
2. 数据里有一个极端异常值，Pearson 和 Spearman 选哪个？为什么？
3. 下表是学习时间、睡眠时间、考试分数的相关矩阵，哪一对最强？能不能据此说“学习导致分数高”？

|  | 学习时间 | 睡眠时间 | 考试分数 |
|---|---|---|---|
| 学习时间 | 1 | −0.2 | 0.7 |
| 睡眠时间 | −0.2 | 1 | 0.5 |
| 考试分数 | 0.7 | 0.5 | 1 |

### 参考答案

1. r = 0.0（精确为 0，离差乘积和正负抵消）。不能说明没关系：y = x² 是强关系，只是非线性，Pearson 只量直线所以量不出来。正确做法是先画散点图，看到抛物线就换模型。
2. 选 Spearman。异常值再大也只占一个名次，拉不动等级相关；Pearson 用原始数值，一个离群点就能把 r 拉跑。顺序数据、有异常值时都优先 Spearman（或 Kendall）。
3. 最强是学习时间–考试分数（0.7）。不能说“学习导致分数高”：相关矩阵没有方向，分数高也可能反向导致多学习，第三变量（如自律性）也可能同时影响两者；因果需要随机对照实验或排除混杂的准实验设计。
