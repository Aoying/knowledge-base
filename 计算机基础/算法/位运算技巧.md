# 位运算技巧

基础操作、常用技巧、经典题、语言陷阱合集。主篇 [数据结构与算法](计算机基础/算法/数据结构与算法.md) 只给了提纲，本篇是可直接抄的版本。

## 基础操作表

| 操作 | 写法 | 例子 |
|---|---|---|
| 与 | `&` | 5 & 3 = 1（101 & 011 = 001） |
| 或 | `\|` | 5 \| 3 = 7（101 \| 011 = 111） |
| 非 | `~` | ~5 = -6（取反后加 1 的补码规则：~x = -x - 1） |
| 异或 | `^` | 5 ^ 3 = 6（101 ^ 011 = 110） |
| 左移 | `<<` | 1 << 3 = 8（乘 2 的 3 次方） |
| 右移 | `>>` | 8 >> 2 = 2（除 2 的 2 次方，向下取整） |

判断奇偶用 `x & 1`：结果 1 为奇数，0 为偶数，比 `x % 2` 更直接。

## 常用技巧

- 取最低位的 1（lowbit）：`x & -x`。例如 12（二进制 1100）的 lowbit 是 4（0100）。
- 清除最低位的 1：`x & (x - 1)`。例如 12 & 11 = 8（1100 & 1011 = 1000）。
- 判断 2 的幂：`x > 0 and x & (x - 1) == 0`。16 通过，18 不通过；`x > 0` 不能省，因为 0 & (0 - 1) == 0 也成立。
- 统计 1 的个数：`bin(x).count("1")`；Python 3.10+ 可用 `int.bit_count()`。例如 13（二进制 1101）是 3 个。
- 操作第 k 位（从 0 数）：取位 `(x >> k) & 1`、置 1 `x | (1 << k)`、清 0 `x & ~(1 << k)`、翻转 `x ^ (1 << k)`。例如 x = 5（二进制 101）：置第 1 位得 7（111），清第 2 位得 1（001），翻第 0 位得 4（100）。
- 异或交换：`a ^= b; b ^= a; a ^= b` 不用临时变量换值；但只适用于 a、b 是两个不同变量——同一个变量自交换第一步就清零（`x ^= x` 得 0，后面全是 0），函数里 `swap(x, x)` 是经典坑；可读性差，现代编译器对临时变量交换的优化已足够好，生产代码优先用临时变量。
- 判断两数符号是否相同：`(a ^ b) >= 0` 为同号（异或后符号位为 0），`< 0` 为异号；比分别判断 `< 0` 少一次分支，只适用于同为有符号整数。
- lowbit 是树状数组的核心：`x & -x` 取最低位 1，树状数组用它跳父节点、求前缀和，详见 [线段树与树状数组](计算机基础/算法/线段树与树状数组.md)。

```python
print(5 & 3, 5 | 3, ~5, 5 ^ 3, 1 << 3, 8 >> 2)  # 1 7 -6 6 8 2
print(12 & -12, 12 & 11)                        # 4 8
print(16 > 0 and 16 & 15 == 0, 18 > 0 and 18 & 17 == 0)  # True False
print(bin(13).count("1"), (13).bit_count())      # 3 3
```

```python
# 第 k 位操作（x = 5，二进制 101）
print((5 >> 2) & 1, 5 | (1 << 1), 5 & ~(1 << 2), 5 ^ (1 << 0))  # 1 7 1 4
# Kernighan 循环：每次清掉最低位 1，循环次数 = 1 的个数
def popcount(x):
    c = 0
    while x:
        x &= x - 1
        c += 1
    return c
print(popcount(13))  # 3
```

## 经典题

### 只出现一次的数字

数组里每个数字都出现两次，只有一个出现一次，求它。异或一遍就是答案。

```python
def single_number(nums):
    x = 0
    for v in nums:
        x ^= v
    return x

print(single_number([2, 2, 1]))        # 1
print(single_number([4, 1, 2, 1, 2]))  # 4
```

原理：异或满足交换律、结合律，且 a ^ a = 0、a ^ 0 = a；成对出现互相抵消，只剩出现 1 次的。

### 只出现一次的数字 II（其余出现 3 次）

按位统计：32 位每一位上 1 的个数 mod 3，余 1 的位拼出答案。例 [2, 2, 3, 2] → 3。

```python
def single_number_ii(nums):
    ans = 0
    for b in range(32):
        if sum((v >> b) & 1 for v in nums) % 3:
            ans |= 1 << b
    if ans & (1 << 31):  # 最高位为 1，答案是负数，转回有符号
        ans -= 1 << 32
    return ans

print(single_number_ii([2, 2, 3, 2]))            # 3
print(single_number_ii([0, 1, 0, 1, 0, 1, 99]))  # 99
print(single_number_ii([-1, -1, -1, -2]))        # -2
```

注意：这版只对非负数直接成立；答案为负数时要把 32 位结果转回有符号（最高位为 1 时减 `1 << 32`）。面试追问的状态机解法（two/one 两个变量模拟三进制计数器）是同一思路的 O(1) 空间版，原理相同。

### 两个只出现一次的数字

全部异或得 `x ^ y`；取它最低位的 1（`diff = xor & -xor`），按该位把数组分两组，各组内异或即得两个答案。例 [1, 2, 1, 3, 2, 5] → 3 和 5：全体异或 6（二进制 110），diff = 2（010），按第 1 位分组 {2, 2, 3} → 3、{1, 1, 5} → 5。

```python
def single_numbers(nums):
    xor = 0
    for v in nums:
        xor ^= v
    diff = xor & -xor
    a = b = 0
    for v in nums:
        if v & diff:
            a ^= v
        else:
            b ^= v
    return sorted([a, b])

print(single_numbers([1, 2, 1, 3, 2, 5]))  # [3, 5]
```

关键：两个目标数在 diff 这一位上必不同（否则该位异或结果为 0），所以分组后它们落在不同组；成对出现的数在该位上相同，落在同一组内互相抵消。

### 丢失的数字

数组含 n 个互不相同的数，取自 0..n，求缺失的那个。例如 [3, 0, 1] 缺 2。

```python
def missing_number(nums):
    x = len(nums)
    for i, v in enumerate(nums):
        x ^= i ^ v
    return x

print(missing_number([3, 0, 1]))  # 2
```

原理：0..n 的异或与数组的异或再异或一次，成对抵消后只剩缺失的数。等价写法是求和法：n(n+1)/2 - sum(nums) = 6 - 4 = 2。

### 汉明距离

两个数不同的二进制位数 = `x ^ y` 里 1 的个数。例 1（001）与 4（100）：异或得 5（101），含 2 个 1，距离为 2。

```python
print(bin(1 ^ 4).count("1"))  # 2，与上节 popcount(1 ^ 4) 等价
```

### 子集枚举

用 mask 的每一位表示取不取对应元素，mask 从 0 到 2^n - 1 扫一遍就是全部子集。

```python
def subsets(nums):
    n = len(nums)
    return [[nums[i] for i in range(n) if mask >> i & 1]
            for mask in range(1 << n)]

print(subsets([1, 2, 3]))
# [[], [1], [2], [1, 2], [3], [1, 3], [2, 3], [1, 2, 3]]
```

子集总数 2^n，n 大了不要全量枚举；n ≤ 20 左右才适合这种写法。

## 注意事项：语言陷阱

- Python 负数是无限位表示：负数在概念上是无限个 1 的补码，`bin(-1)` 得到的是带符号的 `-0b1`，不是补码串，不要拿它数 1 的个数。
- Python 的 `>>` 是算术右移：符号位补 1，所以 `-1 >> 1` 还是 -1（全 1 右移还是全 1）。
- `x & (x - 1)` 对负数不像正数那样直观：负数的补码尾巴全是 1，“清除最低位 1”这句话在负数上容易算错，负数场景先限定非负或转无符号思路。
- Python 数负数 1 的个数先掩码：`(-5) & 0xFFFFFFFF` 的 32 位补码含 31 个 1（不是直接 `bin(-5).count("1")`，后者数的是带符号字符串 `-0b101` 里的 1）。
- Java int 是 32 位：`>>>` 是逻辑右移（高位补 0），`>>` 是算术右移（符号位补 1）；`1 << 31` 会得到负数（符号位被置 1）；int 运算溢出会回绕，不抛异常。
- Java 移位距离取模：`1 << 32` 等于 `1 << 0` 得 1，`1 << 33` 等于 `1 << 1` 得 2——移位距离对 int 取 mod 32、long 取 mod 64（JLS §15.19，int 掩码 31、long 掩码 63）；写 `1 << n` 前先确认 n 的范围，n ≥ 32 时先对 n 取模或改用 long；long 是 64 位，`1L << 63` 得 Long.MIN_VALUE，需要第 31 位以上先写 `1L`。

## 小技巧与冷知识

【小技巧】判断 4 的幂可以在“2 的幂”判定上再加一层掩码：`x > 0 and x & (x - 1) == 0 and x & 0x55555555 != 0`。0x55555555 的 1 都落在偶数位上，4 的幂的唯一 1 必然落在偶数位（1、4、16、64……），而 2、8、32 的唯一 1 在奇数位，会被掩码筛掉；先判 2 的幂再筛位置，比逐个除以 4 快得多。

【小技巧】向上取整到 2 的幂不用循环移位：Python 里 `1 << (n - 1).bit_length()` 一行搞定，n = 5 得 8、n = 8 得 8、n = 9 得 16。原理是 `bit_length()` 给出最高位 1 的位置，减 1 再左移就是“刚好盖住 n 的最小 2 的幂”；n = 1 时结果是 1，写分配容量、对齐缓冲区时直接抄这个式子。

【小技巧】取低 k 位用掩码比取模直观：`x & ((1 << k) - 1)` 就是 x 的低 k 位，比如取低 8 位写 `x & 0xFF`。掩码法只在 k 位内有效、且对负数是补码低位；想取“低 k 位的无符号值”时它比 `x % (1 << k)` 更能表达意图，哈希、打包协议字段时常用。

【小技巧】数末尾 0 的个数不用循环右移：`(x & -x).bit_length() - 1` 就是 trailing zeros，12 得 2、40 得 3。`x & -x`  isolate 出最低位 1，它的 bit_length 减 1 正好是该位下标；判断“x 能被 8 整除”等价于末尾 0 至少 3 个，比 `x % 8 == 0` 更能一眼看出 2 的因子个数。

【小技巧】ASCII 字母大小写切换只要一个异或：`c ^ 32` 能把 'A' 变 'a'、把 'a' 变 'A'，因为大小写字母的 ASCII 码只差第 5 位（32）。但只对字母有效——数字、符号异或 32 会变成控制字符或别的符号，生产代码里先判断 `isalpha` 再翻转，别对任意字符用这招。

【小技巧】求两个数的平均数时 `(a + b) // 2` 在定长整数里可能溢出，换成 `(a & b) + ((a ^ b) >> 1)` 就没有中间和：a 与 b 的公共 1 位直接保留，相异位取一半相加，5 和 7 得 6、-5 和 3 得 -1。Java 里这是不溢出求中点的标准写法之一，写二分查找的中点时同理可套。

【小技巧】区间异或查询可以像前缀和一样预处理：`pref[i+1] = pref[i] ^ a[i]`，区间 [l, r] 的异或就是 `pref[r+1] ^ pref[l]`，一次查询 O(1)。原理和前缀和相同，只是把加法换成异或、减法换成“再异或一次”——成对抵消后只剩区间内的数，区间异或题先想前缀异或，别每问都扫一遍。

【小技巧】枚举一个掩码的全部子掩码不用从 0 扫到 2^n：`sub = mask; sub = (sub - 1) & mask` 循环递减，恰好走遍 mask 的每个子集，数量是 2^(popcount)，比如 mask = 0b10110 只有 8 个子掩码。状态压缩 DP 里枚举“当前集合的子集”就用这招，比全量枚举少走大量无效掩码；记得先处理 sub = mask 本身、最后处理 sub = 0。

【小技巧】格雷码编码是一行：`g = n ^ (n >> 1)`，0 到 7 的格雷码是 0、1、3、2、6、7、5、4，相邻两个数只差一位。解码要逐位异或回推（`n ^= g; g >>= 1` 循环），不能只靠一次移位；需要“相邻状态只变一位”的场景（旋转编码器、卡诺图、爬山搜索）先想格雷码。

【小技巧】Java 里别手写数 1、找最低位这些循环：`Integer.bitCount(x)`、`Integer.lowestOneBit(x)`、`Integer.highestOneBit(x)`、`Integer.numberOfTrailingZeros(x)` 都是标准库现成的，底层多半一条指令。手写 Kernighan 循环是面试写法，生产代码直接调库函数，可读性和速度都更好；Long 也有对应的一套。

【小技巧】C 语言里 `x & 1 == 0` 是个经典坑：C 中 `==` 的优先级高于 `&`，它会被解析成 `x & (1 == 0)` 即 `x & 0`，恒为 0。Python 里 `&` 的优先级高于 `==`，同样写法结果却正确——跨语言抄位运算代码时先加括号写成 `(x & 1) == 0`，别赌自己记得住两边的优先级表。

【小技巧】Python 的整数没有固定位宽，`1 << 100` 直接能算，别按 Java int 的 32 位习惯自我设限：原文 Java 篇的“1 << 31 变负数、移位取模 32”在 Python 里都不存在。但反过来也别把 Python 习惯带回 Java/C++——Python 里 `x >> 1` 对大正数永远安全，Java 里 `1 << n` 的 n ≥ 32 就要先取模或改 long。

【冷知识】快速平方根倒数里的魔法数 `0x5f3759df` 是位运算史上最出名的常数：1999 年《Quake III Arena》源码里用整数位运算直接猜出 `1/sqrt(x)` 的近似值，再牛顿迭代一两次就够准。它利用了 IEEE 754 浮点数的指数位结构，把浮点数当整数移位、减去魔法数来逼近对数，省掉了当时昂贵的除法和开方。

【冷知识】格雷码是 1947 年贝尔实验室的 Frank Gray 申请的专利（1953 年授权），最初为旋转编码器设计：编码盘转动时相邻位置只变一位，多位同时翻转的毛刺就不会出现。格雷码不是为了好看，是硬件上“一次只变一位才可靠”的工程需求催生的编码，数字电路里至今还在用。

【冷知识】数 1 的个数在硬件里是一条指令：x86 的 POPCNT 随 SSE4.2 在 2008 年的 Nehalem 处理器上引入，一条指令数完一个 64 位数里 1 的个数。现代语言的 `bit_count()` 在支持的平台上能走到这条指令，所以“数 1”在今天既是位运算技巧，也是硬件指令——手写循环纯粹是为了理解原理。

【冷知识】C++20 之前，有符号整数右移是“实现定义”的行为：标准只说结果由实现决定，实践中几乎所有编译器都做算术右移（补符号位），C++20 才正式把它规定为算术右移；C 语言至今仍是实现定义。跨编译器、跨平台的位运算代码别依赖“负数右移一定补 1”，要逻辑右移就先转无符号。

【冷知识】RAID-5 的校验盘本质就是异或：同一条带上各盘同位置的数据异或得到校验块，任意一块盘坏了，用其余盘加校验块再异或一次就能还原。原文“异或成对抵消”的性质在这里是存储层面的应用——`a ^ b ^ b = a`，坏盘的数据就是被校验块“抵消”后剩下的那一份。

【冷知识】Unix 文件权限本身就是位掩码：rwx 各占 1 位，一组三位、共三组，755 展开就是 rwxr-xr-x。`chmod` 的数字写法不是“数字”，是八进制写的位掩码——每一位对应一个开关，位运算里“用位表示开关集合”的思想，操作系统权限就是最日常的例子。

## 面试与自测

1. 为什么 `x & (x - 1)` 能清除最低位的 1？x = 12 时结果是多少？
2. 只出现一次的数字为什么异或一遍就行？如果“其余数字都出现 3 次、一个出现 1 次”，异或还管用吗？
3. Python 里 `-1 >> 1` 为什么是 -1？Java 里想逻辑右移写什么？
4. 数组 [1, 2, 1, 3, 2, 5] 里两个只出现一次的数怎么找？为什么按 `xor & -xor` 那一位分组就能分开它们？

### 参考答案

1. x - 1 会把最低位 1 变 0、更低位全变 1（若最低位 1 后面有 0 则那些 0 变 1），与 x 按位与后最低位 1 被清掉、更高位不变；12（二进制 1100）→ 8（1000）。
2. 异或满足交换律、结合律且 a ^ a = 0、a ^ 0 = a，成对出现互相抵消，只剩出现 1 次的。出现 3 次时 a ^ a ^ a = a，不抵消，异或法失效，要按位统计后 mod 3（或状态机）。
3. Python 的 `>>` 是算术右移，符号位补 1；-1 的无限位补码全是 1，右移还是全 1 即 -1。Java 里逻辑右移用 `>>>`（高位补 0），`>>` 是算术右移。
4. 全体异或得 6（二进制 110），最低位 1 在第 1 位；两个目标数在该位上必不同（否则该位异或结果为 0），按该位分组后它们落在不同组，每组内成对数抵消，组内异或即得目标数；结果 3 和 5。
