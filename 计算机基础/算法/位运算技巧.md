# 位运算技巧

基础操作、常用技巧、经典题、语言陷阱合集。主篇 [数据结构与算法](计算机基础/算法/数据结构与算法.md) 只给了提纲，本篇是可直接抄的版本。

## 基础操作表

| 操作 | 写法 | 例子 |
|---|---|---|
| 与 | `&` | 5 & 3 = 1（101 & 011 = 001） |
| 或 | `\|` | 5 \| 3 = 7（101 \| 011 = 111） |
| 非 | `~` | ~5 = -6（取反后加 1 的补码规则：~x = -x - 1） |
| 异或 | `^` | 5 ^ 3 = 6（101 ^ 011 = 110） |
| 左移 | `<<` | 1 << 3 = 8（乘 2 的 3 次方） |
| 右移 | `>>` | 8 >> 2 = 2（除 2 的 2 次方，向下取整） |

判断奇偶用 `x & 1`：结果 1 为奇数，0 为偶数，比 `x % 2` 更直接。

## 常用技巧

- 取最低位的 1（lowbit）：`x & -x`。例如 12（二进制 1100）的 lowbit 是 4（0100）。
- 清除最低位的 1：`x & (x - 1)`。例如 12 & 11 = 8（1100 & 1011 = 1000）。
- 判断 2 的幂：`x > 0 and x & (x - 1) == 0`。16 通过，18 不通过；`x > 0` 不能省，因为 0 & (0 - 1) == 0 也成立。
- 统计 1 的个数：`bin(x).count("1")`；Python 3.10+ 可用 `int.bit_count()`。例如 13（二进制 1101）是 3 个。

```python
print(5 & 3, 5 | 3, ~5, 5 ^ 3, 1 << 3, 8 >> 2)  # 1 7 -6 6 8 2
print(12 & -12, 12 & 11)                        # 4 8
print(16 > 0 and 16 & 15 == 0, 18 > 0 and 18 & 17 == 0)  # True False
print(bin(13).count("1"), (13).bit_count())      # 3 3
```

## 经典题

### 只出现一次的数字

数组里每个数字都出现两次，只有一个出现一次，求它。异或一遍就是答案。

```python
def single_number(nums):
    x = 0
    for v in nums:
        x ^= v
    return x

print(single_number([2, 2, 1]))        # 1
print(single_number([4, 1, 2, 1, 2]))  # 4
```

原理：异或满足交换律、结合律，且 a ^ a = 0、a ^ 0 = a；成对出现互相抵消，只剩出现 1 次的。

### 丢失的数字

数组含 n 个互不相同的数，取自 0..n，求缺失的那个。例如 [3, 0, 1] 缺 2。

```python
def missing_number(nums):
    x = len(nums)
    for i, v in enumerate(nums):
        x ^= i ^ v
    return x

print(missing_number([3, 0, 1]))  # 2
```

原理：0..n 的异或与数组的异或再异或一次，成对抵消后只剩缺失的数。等价写法是求和法：n(n+1)/2 - sum(nums) = 6 - 4 = 2。

### 子集枚举

用 mask 的每一位表示取不取对应元素，mask 从 0 到 2^n - 1 扫一遍就是全部子集。

```python
def subsets(nums):
    n = len(nums)
    return [[nums[i] for i in range(n) if mask >> i & 1]
            for mask in range(1 << n)]

print(subsets([1, 2, 3]))
# [[], [1], [2], [1, 2], [3], [1, 3], [2, 3], [1, 2, 3]]
```

子集总数 2^n，n 大了不要全量枚举；n ≤ 20 左右才适合这种写法。

## 注意事项：语言陷阱

- Python 负数是无限位表示：负数在概念上是无限个 1 的补码，`bin(-1)` 得到的是带符号的 `-0b1`，不是补码串，不要拿它数 1 的个数。
- Python 的 `>>` 是算术右移：符号位补 1，所以 `-1 >> 1` 还是 -1（全 1 右移还是全 1）。
- `x & (x - 1)` 对负数不像正数那样直观：负数的补码尾巴全是 1，“清除最低位 1”这句话在负数上容易算错，负数场景先限定非负或转无符号思路。
- Java int 是 32 位：`>>>` 是逻辑右移（高位补 0），`>>` 是算术右移（符号位补 1）；`1 << 31` 会得到负数（符号位被置 1）；int 运算溢出会回绕，不抛异常。

## 面试与自测

1. 为什么 `x & (x - 1)` 能清除最低位的 1？x = 12 时结果是多少？
2. 只出现一次的数字为什么异或一遍就行？如果“其余数字都出现 3 次、一个出现 1 次”，异或还管用吗？
3. Python 里 `-1 >> 1` 为什么是 -1？Java 里想逻辑右移写什么？

### 参考答案

1. x - 1 会把最低位 1 变 0、更低位全变 1（若最低位 1 后面有 0 则那些 0 变 1），与 x 按位与后最低位 1 被清掉、更高位不变；12（二进制 1100）→ 8（1000）。
2. 异或满足交换律、结合律且 a ^ a = 0、a ^ 0 = a，成对出现互相抵消，只剩出现 1 次的。出现 3 次时 a ^ a ^ a = a，不抵消，异或法失效，要按位统计后 mod 3（或状态机）。
3. Python 的 `>>` 是算术右移，符号位补 1；-1 的无限位补码全是 1，右移还是全 1 即 -1。Java 里逻辑右移用 `>>>`（高位补 0），`>>` 是算术右移。
