# 动态规划模板与经典题型

动态规划（DP）只有一句话：把大问题拆成小问题，记住小问题的答案，别重复算。做题时按五步走，缺一步都容易错。

## DP 模板五步

1. 状态定义：`dp[i]`（或 `dp[i][j]`）到底表示什么，必须是一句话能说清的量。
2. 转移方程：`dp[i]` 由哪些更小的状态算出来。
3. 初始化：边界状态的值，不能靠转移方程自己推出来。
4. 遍历顺序：保证算 `dp[i]` 时它依赖的状态已经算过。
5. 举例推导：拿一个小例子手推一遍 dp 表，确认转移和初始化没错再写代码。

## 经典题 1：0-1 背包

每件物品只能选一次。状态 `dp[c]` 表示容量为 `c` 时的最大价值；转移是“选或不选”：`dp[c] = max(dp[c], dp[c - w] + v)`。一维版必须倒序遍历容量，否则同一件物品会被重复选，变成完全背包。

```python
def knapsack(weights, values, capacity):
    dp = [0] * (capacity + 1)
    for w, v in zip(weights, values):
        for c in range(capacity, w - 1, -1):
            dp[c] = max(dp[c], dp[c - w] + v)
    return dp
```

worked 例：重量 `[1, 3, 4]`，价值 `[15, 20, 30]`，容量 `4`。最终 `dp = [0, 15, 15, 20, 35]`，答案 `35`，对应选 1kg 和 3kg 两件（`15 + 20`）；单选 4kg 只有 30，不如组合。

## 经典题 2：最长递增子序列（LIS）

状态 `dp[i]` 表示以 `nums[i]` 结尾的最长递增子序列长度；转移 `dp[i] = max(dp[j] + 1)`，其中 `j < i` 且 `nums[j] < nums[i]`；初始化全为 1（每个元素自成长度 1 的子序列）。

```python
def lis(nums):
    dp = [1] * len(nums)
    for i in range(len(nums)):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)
```

worked 例：`[10, 9, 2, 5, 3, 7, 101, 18]`，dp 表是 `[1, 1, 1, 2, 2, 3, 4, 4]`，答案 `4`（如 `[2, 3, 7, 101]`）。注意这版是 O(n²)；还有 O(n log n) 的贪心 + 二分写法，思路不同，不在本篇模板内展开。

## 经典题 3：最长公共子序列（LCS）

状态 `dp[i][j]` 表示 `a` 前 `i` 个字符与 `b` 前 `j` 个字符的最长公共子序列长度；转移：`a[i-1] == b[j-1]` 时 `dp[i][j] = dp[i-1][j-1] + 1`，否则 `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`；首行首列初始化为 0。

```python
def lcs(a, b):
    dp = [[0] * (len(b) + 1) for _ in range(len(a) + 1)]
    for i in range(len(a)):
        for j in range(len(b)):
            if a[i] == b[j]:
                dp[i + 1][j + 1] = dp[i][j] + 1
            else:
                dp[i + 1][j + 1] = max(dp[i][j + 1], dp[i + 1][j])
    return dp[len(a)][len(b)]
```

worked 例：`"abcde"` 与 `"ace"`，答案 `3`，即 `"ace"` 本身。易混点：最长公共子串要求连续，不相等时 `dp[i][j]` 要归零，不能取 max——子序列和子串的转移不一样。

## 经典题 4：打家劫舍

状态 `dp[i]` 表示前 `i` 间房能偷到的最高金额；转移 `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`，即“不偷第 `i` 间”和“偷第 `i` 间（那第 `i-1` 间就不能偷）”取大。只依赖前两项，可以压缩成两个变量。

```python
def rob(nums):
    prev2, prev1 = 0, 0  # prev2 = dp[i-2]，prev1 = dp[i-1]
    for x in nums:
        prev2, prev1 = prev1, max(prev1, prev2 + x)
    return prev1
```

worked 例：`[2, 7, 9, 3, 1]`，答案 `12`，对应偷第 1、3、5 间（`2 + 9 + 1`）；偷 7 和 9 相邻是非法的，偷 7、3、1 只有 11。

## 复杂度小结

| 题 | 时间 | 空间 |
|---|---|---|
| 0-1 背包（一维） | O(n × 容量) | O(容量) |
| LIS（O(n²) 版） | O(n²) | O(n) |
| LCS | O(mn) | O(mn)，可压缩到 O(min(m, n)) |
| 打家劫舍 | O(n) | O(1)（滚动变量） |

## 常见误区

- 背包一维正序遍历：同一件物品会被反复选，0-1 背包悄悄变成完全背包；一维版必须倒序。
- LIS 初始化写成全 0：每个元素自成长度 1 的子序列，初始化必须是全 1，否则答案会少 1。
- LCS 与最长公共子串混用转移：子序列不相等时取 max，子串不相等时归零，写错一个分支整题就错。
- 状态定义含糊：`dp[i]` 到底是“前 i 个”还是“以 i 结尾”，说不清就写不出转移方程；先写一句话定义再动笔。

## 进阶：区间 DP 与树形 DP

上面四题都是一维线性 DP。状态本身带结构时，DP 的维度跟着变：

- 区间 DP：状态是区间 `dp[l][r]`，表示区间 [l, r] 上的最优解。区间从小到大枚举长度，转移时枚举中间断点 k，把区间拆成 [l, k] 和 [k+1, r] 两段合并。典型题：石子合并（合并代价最小）、最长回文子序列（两端相等则 2 + dp[l+1][r-1]，否则 max(dp[l+1][r], dp[l][r-1])）。复杂度通常是 O(n³)，因为长度、左端点、断点三层循环。
- 树形 DP：状态挂在树节点上，自底向上回推。每个节点返回一组值而不是一个值，典型是打家劫舍 III：对每个节点返回 [不偷该节点的最大收益，偷该节点的最大收益]，不偷 = 左右孩子各取 max（偷，不偷），偷 = 节点值 + 左右孩子的不偷值。另一个典型是树的直径：对每个节点算经过该节点的最长路径（左高 + 右高），答案是所有节点取 max。

共同点：状态定义仍是第一步——区间 DP 先说清 `dp[l][r]` 是什么，树形 DP 先说清每个节点返回哪几个值；定义不清，后面的转移照样写不出来。

## 小技巧与冷知识

【小技巧】先写带缓存的递归，再改递推：递归版的函数签名就是状态定义（参数是状态，返回值是 dp 值），转移方程直接写成递归式，验证思路比递推直观。递归版跑通小例子确认转移无误后，再按依赖方向改成循环填表，改的过程中转移逻辑一行都不用变。

【小技巧】调 DP 先打印 dp 表，不要只看最终答案：小例子手推一遍 dp 表，错在哪一行、哪一列一目了然——初始化错了错在首行首列，转移错了错在某一格开始往后全错，遍历顺序错了则是依赖的格子还没算出来就被用了。只看最终答案错多少，定位不到是哪一步出的问题。

【小技巧】“恰好装满”类背包，dp 数组初始化要用 -inf 而不是 0：0 表示“容量为 0 时价值 0”这个可达状态，拿它当默认值会把“根本装不满”的容量也当成可达。不可达状态用 -inf 标记，转移时跳过 -inf 的前驱，最后答案仍是 -inf 就说明无解。

【小技巧】同一套转移，改遍历顺序就换题型：0-1 背包倒序是“每件只用一次”，改成正序就变成完全背包（每件无限次）。这不是两套模板，是同一条转移方程在“用本轮状态还是上一轮状态”上的两种选择；写 DP 时先问一句“这个状态允许用本轮刚算出的值吗”，顺序就定下来了。

【小技巧】状态能不能压缩成滚动变量，先看依赖范围：只依赖前一项、前两项（如打家劫舍）才能压成两个变量；依赖整行（如 LCS 的 dp[i-1][j]、dp[i][j-1]）只能压到一维再加一个临时变量存左上角。压缩前先把依赖的格子画出来，依赖跨了几行，压缩后就要留几个变量。

【小技巧】二维 dp 填表前先画依赖箭头：dp[i][j] 依赖的是上方、左方还是左上方，决定了 i、j 哪个先枚举。LCS 依赖上方和左方，行列顺序可以换；有的题依赖左上方，就必须保证左上方的格子先算。顺序错了，填出来的表看着像样、答案全错。

【小技巧】区间 DP 必须按区间长度从小到大枚举：dp[l][r] 依赖的是更短的区间 [l+1, r]、[l, r-1] 或拆成两段的子区间，长度小的区间一定要先算完。按左端点顺序枚举是错的——左端点小的区间不一定短，依赖可能还没算出来。

【小技巧】上 DP 之前先验证最优子结构：局部最优能拼出全局最优，DP 才成立。有些题看着像 DP，子问题的最优解拼不出原问题的最优解（比如带全局约束的路径问题），硬套模板会得到一个“看起来合理、实际错误”的答案；先想清楚“子问题最优 → 原问题最优”这一步通不通，再写状态。

【小技巧】只求最优值和要还原最优解是两件事：求值只要填表，求解还要回溯。回溯时从答案所在的格子出发，看它是由哪个前驱转移来的，一步步倒推回起点，就得到一组最优选择。写代码时顺手记“每个格子由哪个前驱来”，回溯就是查表，不用重新算。

【小技巧】打家劫舍的环形版不用重写转移，分两种情况取大：第一间和最后一间不能同时偷，所以拆成“偷第一间、不偷最后一间”和“不偷第一间、可以偷最后一间”两个线性问题，各跑一遍原文的转移取 max。环形约束的处理思路就是“把环断开，枚举断点处的状态”。

【小技巧】LIS 的 O(n log n) 版只能求长度，不能还原具体序列：它维护的是“长度为 k 的递增子序列的最小可能尾元素”，这个数组本身不是一条真实的子序列。需要输出序列内容时用 O(n²) 版加前驱指针，别拿贪心版的数组当答案序列交出去。

【冷知识】“动态规划”这个名字是 Richard Bellman 在 1950 年代起的，programming 在这里是“规划、调度”的意思，不是写程序。Bellman 在自传里说过，选这个名字 partly 是为了让军方资助者觉得它不像纯数学研究——一个带点工程味的名字，更容易拿到经费。

【冷知识】动态规划成立要同时满足两个条件，缺一不可：最优子结构（子问题最优能拼出原问题最优）+ 重叠子问题（同一个子问题会被反复用到）。分治只有前者没有后者，所以分治不用记答案、直接递归就行；DP 多出来的“记答案”这一步，省的正是重复计算。

【冷知识】0-1 背包的 O(n × 容量) 不是真正的多项式时间：它是伪多项式时间，复杂度里的“容量”是数值大小，不是输入长度。容量写成二进制只要 log(容量) 位，容量翻倍输入只长 1 位、时间却翻倍；容量大到几十亿时，这套 DP 根本跑不动，背包问题本身是 NP-hard。

【冷知识】LCS 还有个 Hirschberg 算法，能把空间压到 O(min(m, n)) 的同时还原出具体序列：它用分治 + 前后各算一半 dp，把序列在中间切开，递归处理两半。原文说的“可压缩到 O(min(m, n))”只压空间不还原序列，Hirschberg 是“既省空间又能还原”的完整方案，1975 年发表。

## 面试与自测

1. 0-1 背包一维版为什么必须倒序遍历容量？正序会发生什么？
2. LIS 的 O(n²) 版和 O(n log n) 版思路有什么本质不同？
3. 打家劫舍的转移 `dp[i] = max(dp[i-1], dp[i-2] + nums[i])` 里，两项分别对应什么决策？

### 参考答案

1. 倒序保证 `dp[c - w]` 还是上一轮（没选当前物品）的状态，所以每件物品只被用一次；正序时 `dp[c - w]` 可能已经是本轮选过当前物品后的值，同一件物品会被重复选，问题就变成了完全背包。
2. O(n²) 版是标准 DP：`dp[i]` 由所有 `j < i` 转移来；O(n log n) 版是贪心 + 二分：维护一个“长度为 k 的递增子序列的最小可能尾元素”数组，用二分找替换位置，只求长度不求具体序列，两者思路不同。
3. `dp[i-1]` 对应不偷第 `i` 间（沿用前 `i-1` 间的最优）；`dp[i-2] + nums[i]` 对应偷第 `i` 间，那第 `i-1` 间不能偷，只能沿用前 `i-2` 间的最优再加上当前这间。
