# 前缀和与差分

前缀和与差分是一对互逆的预处理技巧：前缀和把“区间查询”变成 O(1)，差分把“区间修改”变成 O(1)。两者都不支持“边改边查”，那是树状数组/线段树的活。

## 一维前缀和

定义：`pre[0] = 0`，`pre[i+1] = pre[i] + nums[i]`，即 `pre[i]` 是前 `i` 个元素的和。区间和 `sum(l, r)`（闭区间）= `pre[r+1] - pre[l]`。

```python
def build_prefix(nums):
    pre = [0] * (len(nums) + 1)
    for i, x in enumerate(nums):
        pre[i + 1] = pre[i] + x
    return pre

def range_sum(pre, l, r):
    return pre[r + 1] - pre[l]
```

### worked 例

`nums = [3, 1, 4, 1, 5, 9]`，逐步累加得：

```
pre = [0, 3, 4, 8, 9, 14, 23]
```

- `sum(1, 3) = pre[4] - pre[1] = 9 - 3 = 6`，对应 `1 + 4 + 1 = 6`。
- `sum(0, 5) = pre[6] - pre[0] = 23 - 0 = 23`，即全数组和。

## 二维前缀和

定义：`ps[i+1][j+1] = mat[i][j] + ps[i][j+1] + ps[i+1][j] - ps[i][j]`。矩形 `(r1, c1)` 到 `(r2, c2)`（闭区间）的和 = `ps[r2+1][c2+1] - ps[r1][c2+1] - ps[r2+1][c1] + ps[r1][c1]`，最后加回来的 `ps[r1][c1]` 是被减了两次的左上角重叠区。

### worked 例

`mat = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]`：

- 右下角 `2x2` 子矩阵 `(1, 1)` 到 `(2, 2)`：`5 + 6 + 8 + 9 = 28`，公式算出 `45 - 6 - 12 + 1 = 28`。
- 全矩阵和：`45`。

## 差分数组

定义：`diff[0] = arr[0]`，`diff[i] = arr[i] - arr[i-1]`。差分是前缀和的逆运算：对 `diff` 求前缀和就还原出 `arr`。

区间加 `[l, r] += v` 只需两步：`diff[l] += v`；若 `r + 1 < n`，`diff[r+1] -= v`。还原时对 `diff` 做一次前缀和即可。

```python
def range_add(diff, l, r, v):
    diff[l] += v
    if r + 1 < len(diff):
        diff[r + 1] -= v

def restore(diff):
    out, s = [], 0
    for d in diff:
        s += d
        out.append(s)
    return out
```

### worked 例

`arr = [1, 2, 3, 4, 5]`，差分是 `[1, 1, 1, 1, 1]`。区间 `[1, 3] += 10` 后差分变为 `[1, 11, 1, 1, -9]`，还原得 `[1, 12, 13, 14, 5]`，与直接加逐项核对一致。

多次区间加（从全 0 数组起）：`[0, 2] += 5`，`[1, 4] += 3`，还原得 `[5, 8, 8, 3, 3]`。逐项核对：位置 0 只吃到第一次加法得 5；位置 1、2 两次都吃到得 8；位置 3、4 只吃到第二次得 3。

## 复杂度对比

| 操作 | 暴力 | 前缀和 / 差分 |
|---|---|---|
| 一维区间和查询 | 每次 O(n) | 构造 O(n)，查询 O(1) |
| 二维矩形和查询 | 每次 O(mn) | 构造 O(mn)，查询 O(1) |
| 区间加 | 每次 O(n) | 每次 O(1)，最后还原 O(n) |

## 适用场景与边界

- 前缀和适合：静态数组 + 频繁区间和查询（如子数组和、矩阵区域和）。
- 差分适合：频繁区间加、最后统一看结果（如航班预订统计、区间加法题）。
- 边界：区间修改后前缀和失效——改一个元素，后面所有前缀和都要变；要“边改边查”请用树状数组或线段树，不要硬套前缀和。
- 坑：`pre` 长度是 `n + 1`，查询用 `pre[r+1] - pre[l]`，不是 `pre[r] - pre[l]`；二维公式最后要加回 `ps[r1][c1]`；差分区间加时 `r + 1` 越界要跳过，不要写出界。

## 面试与自测

1. 前缀和构造是 O(n)、查询是 O(1)，为什么不能反过来做到构造 O(1)、查询 O(1)？
2. 对数组做了一次区间修改后，为什么原来的前缀和不能继续用？
3. 差分数组还原为什么就是对差分求前缀和？

### 参考答案

1. 查询 O(1) 的代价就是构造时把累积信息提前算好：`pre` 的每一项都依赖前一项，必须从左到右扫一遍，所以构造至少是 O(n)；不存在不花时间就得到全部累积信息的方法。
2. 因为 `pre[i]` 的定义是前 `i` 个元素的和，改动位置 `p` 之后所有 `i > p` 的 `pre[i]` 都变了；只有把受影响的后缀重算一遍（O(n)）或换支持单点修改的数据结构才能继续查。
3. 因为差分定义就是相邻元素的差：`arr[i] = diff[0] + diff[1] + ... + diff[i]`，把差分从头累加恰好把每一步的差补回去，得到的就是原数组。
