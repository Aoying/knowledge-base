# 滑动窗口与双指针

总纲 [数据结构与算法](计算机基础/算法/数据结构与算法.md) 已把双指针和滑动窗口列为高频模式。本篇讲变长窗口的通用模板、最小覆盖子串、快慢指针、对撞指针。求固定窗口内的最值是另一类问题，用单调队列，见 [单调栈与单调队列](计算机基础/算法/单调栈与单调队列.md)，本篇不重复。

## 变长窗口模板：右扩左缩

窗口 [l, r] 的右端只前进不后退，左端在窗口不满足条件时收缩。每个元素最多进窗口一次、出窗口一次，所以是 O(n)，不是“两层循环就是 O(n²)”。

```python
def longest_unique(s):
    last, l, best = {}, 0, 0
    for r, ch in enumerate(s):
        if ch in last and last[ch] >= l:
            l = last[ch] + 1  # 左端直接跳到上次出现位置的下一位
        last[ch] = r
        best = max(best, r - l + 1)
    return best

print(longest_unique("abcabcbb"))  # 3：最长无重复子串是 "abc"
print(longest_unique("bbbbb"))     # 1
print(longest_unique(""))         # 0
```

worked 走一遍 "abcabcbb"（下标：a0 b1 c2 a3 b4 c5 b6 b7）：r = 0、1、2 窗口 "abc"，最大值 3；r = 3（a）时上次 a 在 0，左端跳到 1，窗口 "bca"，长 3；r = 4（b）时上次 b 在 1，左端跳到 2，窗口 "cab"，长 3；r = 5（c）时上次 c 在 2，左端跳到 3，窗口 "abc"，长 3；r = 6（b）时上次 b 在 4，左端跳到 5，窗口 "cb"，长 2；r = 7（b）时上次 b 在 6，左端跳到 7，窗口 "b"，长 1；全程最大值 3。

模板三要素，写代码前先定好：窗口内维护什么状态（上例是“字符上次出现位置”）、什么时候收缩左端（出现重复）、收缩时状态怎么更新（左端跳过重复字符）。

## 最小覆盖子串：窗口 + 计数

覆盖类问题（窗口必须包含目标的全部字符）用“还差几个”计数：need 记目标每种字符还差几个，have 记窗口里已凑齐几种。

```python
from collections import Counter

def min_window(s, t):
    need = Counter(t)
    missing = len(need)
    l, best = 0, ""
    for r, ch in enumerate(s):
        if ch in need:
            need[ch] -= 1
            if need[ch] == 0:
                missing -= 1
        while missing == 0:  # 窗口已覆盖，尝试从左收缩找更短的
            if not best or r - l + 1 < len(best):
                best = s[l:r + 1]
            left = s[l]
            if left in need:
                if need[left] == 0:
                    missing += 1
                need[left] += 1
            l += 1
    return best

print(min_window("ADOBECODEBANC", "ABC"))  # BANC
```

worked 核对：第一次覆盖出现在 r = 5（窗口 [0, 5] "ADOBEC"，含 A、B、C），收缩：左端 A 移出后缺 A，停，最优 "ADOBEC"（长 6）；r = 10 时再次覆盖，左端从 1 收缩到 6，最优不变；r = 12 时覆盖，左端从 6 收缩：[6, 12] "ODEBANC"（长 7）、[7, 12] "DEBANC"（长 6）都不更短，[8, 12] "EBANC"（长 5）更新，[9, 12] "BANC"（长 4）再更新，随后 B 移出缺 B，停。结果 "BANC"。

注意收缩条件是 `while missing == 0` 不是 `if`：一次右扩可能让左端连续收缩多步，每步都要更新最优解。

## 快慢指针：链表判环与找环入口

快指针一次走两步，慢指针一次走一步；有环时快指针会在环里绕圈追上慢指针，无环时快指针先到终点。找环入口的数学：设头到入口 a 步，入口到相遇点 b 步，环长 c 步；相遇时慢走了 a + b，快走了 a + b + kc（多绕 k 圈），快是慢的两倍：2(a + b) = a + b + kc，得 a = kc - b。也就是说，让一个指针回头从头走 a 步，另一个从相遇点走 kc - b 步，两者同时到达入口。

```python
def find_cycle_entry(nxt, head):
    slow = fast = head
    while fast is not None and nxt[fast] is not None:
        slow = nxt[slow]
        fast = nxt[nxt[fast]]
        if slow == fast:  # 相遇，有环
            p = head
            while p != slow:  # 一个回头，一个原地同速走，相遇即入口
                p = nxt[p]
                slow = nxt[slow]
            return p
    return None

# 链表 0->1->2->3->4->5->3，环是 3-4-5，入口是 3
nxt = [1, 2, 3, 4, 5, 3]
print(find_cycle_entry(nxt, 0))  # 3
print(find_cycle_entry([1, 2, 3, None], 0))  # None：无环
```

同一家族的还有：找链表中点（快到终点时慢正好在中点）、删倒数第 k 个节点（快先走 k 步，再同速走，快到终点时慢在倒数第 k 个）。共同点是“用速度差换位置关系”，不用先数长度。

## 对撞指针：有序数组两数之和

数组有序时，左右指针从两端往中间夹：和太大，右指针左移（和变小）；和太小，左指针右移（和变大）。每步排除一个不可能的组合，整体 O(n)。

```python
def two_sum_sorted(nums, target):
    l, r = 0, len(nums) - 1
    while l < r:
        s = nums[l] + nums[r]
        if s == target:
            return l, r
        if s < target:
            l += 1
        else:
            r -= 1
    return None

print(two_sum_sorted([2, 7, 11, 15], 9))  # (0, 1)：2 + 7 = 9
```

三数之和是同一思想的扩展：先固定一个数，剩下两个用对撞指针；数组有重复时，固定数和对撞指针都要跳过相同值，否则出重复解。

## 适用场景对照

| 工具 | 适用条件 | 典型题 |
| --- | --- | --- |
| 变长窗口 | 连续子数组/子串 + 窗口状态可增量维护 | 最长无重复子串、最小覆盖子串 |
| 快慢指针 | 链表（或数组模拟的链表），不用下标随机访问 | 判环、找环入口、找中点 |
| 对撞指针 | 有序数组，两数关系单调 | 两数之和、三数之和 |
| 单调队列 | 固定窗口内的最值 | 滑动窗口最大值（见单调队列篇） |

## 常见误区

- 变长窗口里左端收缩用 `if` 只缩一步：覆盖类问题一次右扩可能要连缩多步，必须用 `while`。
- 最长无重复子串里左端更新要取 max：`l = max(l, last[ch] + 1)`，不能直接 `l = last[ch] + 1`——上次出现位置可能已经在窗口左端之前（比如 "abba"，第二个 b 处理时左端不能倒退）。
- 上面代码里 `if ch in last and last[ch] >= l` 就是 max 的等价写法：上次出现位置在窗口外时不移动左端。
- 快慢指针判环时快指针的判空要写两步：`fast is not None and nxt[fast] is not None`，只判一步会在链表尾部多走一步越界。
- 对撞指针的前提是有序：无序数组上对撞没有单调性保证，先排序（O(n log n)）或改用哈希表。

## 面试与自测

1. 变长窗口为什么是 O(n) 而不是 O(n²)？左端收缩为什么必须用 while？
2. 快慢指针相遇后，为什么一个指针回头、另一个原地同速走，相遇点就是环入口？
3. 对撞指针为什么要求数组有序？三数之和里重复解是怎么产生的、怎么避免？

### 参考答案

1. 右端从左到右只走一遍，左端也只向右走一遍，每个元素最多进窗口一次、出窗口一次，总操作 O(n)，内层 while 只是把左端推进的总次数分摊到了各步。覆盖类问题一次右扩可能让窗口连续多步都不满足条件，必须用 while 连缩到重新满足为止，if 只缩一步会漏掉更短的合法窗口。
2. 设头到入口 a 步，入口到相遇点 b 步，环长 c 步；相遇时慢走 a + b，快走 a + b + kc（多绕 k 圈），2(a + b) = a + b + kc 得 a = kc - b。回头的指针走 a 步到入口，原地的指针走 kc - b 步也正好到入口（绕 k 圈减 b 步），两者同时到达，所以相遇点就是入口。
3. 对撞依赖单调性：和太大时右指针左移一定让和变小，和太小时左指针右移一定让和变大，每步排除一个不可能组合；无序时移动指针无法保证和的变化方向，结论不成立。三数之和里重复解来自相同的固定数或相同的对撞组合：固定数跳过与上一个相同的值，对撞指针移动后也跳过相同值，才能保证每个三元组只出现一次。
