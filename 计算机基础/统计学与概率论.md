# 统计学与概率论

> AI 转型线的数学底座：机器学习、深度学习、模型评测里天天用的概念都从这里来。本篇只讲够用的部分，不做数学证明，每节都给 Python 复现方向。

## 1. 描述统计：先看清数据长什么样

- 集中趋势：均值（怕极端值）、中位数（稳健）、众数（离散值最常用）。
- 离散程度：方差、标准差、四分位距 IQR（Q3−Q1，箱线图的核心）。
- 分布形状：偏度（左偏/右偏）、峰度；均值 ≠ 中位数时先怀疑偏态，别直接上均值。
- Python：`numpy.mean/median/std`、`pandas.describe()` 一把梭，先看 describe 再建模。

## 2. 概率基础：三句话够用

- 条件概率：P(A|B) = P(A∩B) / P(B)，B 发生后 A 的概率被重新加权。
- 独立性：P(A∩B) = P(A)·P(B) 时独立；现实中特征很少真正独立，朴素贝叶斯就是靠“假装独立”换速度。
- 全概率与期望：期望 E[X] 是加权平均；大数定律保证样本均值随样本量增大趋近期望——评测集太小，指标抖动首先怀疑样本量。

## 3. 常见分布：认出分布就认出了场景

| 分布 | 场景 | 关键参数 |
|---|---|---|
| 正态分布 | 测量误差、身高、模型残差 | 均值 μ、标准差 σ |
| 二项分布 | n 次独立成败（如点击/转化） | n、成功概率 p |
| 泊松分布 | 单位时间/空间内稀有事件数 | 均值 λ |
| 指数分布 | 事件间隔时间（无记忆性） | 速率 λ |
| 均匀分布 | 随机采样、初始化 | 区间 [a, b] |

- 中心极限定理：样本均值的分布随 n 增大趋近正态——这是“均值 ± 1.96·标准误”这类区间估计的根基。
- Python：`scipy.stats.norm/binom/poisson` 查概率密度、累积概率、分位数。

## 4. 贝叶斯：先验 + 证据 = 后验

- 公式：P(θ|D) ∝ P(D|θ)·P(θ)，后验 ∝ 似然 × 先验。
- 直觉：先验是你动手前已有的判断，证据来了按比例修正，别只看似然（这就是“ prosecutor 谬误”的反面教材）。
- 落点：垃圾邮件分类（朴素贝叶斯）、A/B 检验的贝叶斯版、推荐系统的先验平滑。

## 5. 假设检验：p 值到底在说什么

- 原假设 H0（默认无效果）vs 备择假设 H1；p 值 = 在 H0 成立的前提下，看到当前或更极端数据的概率。
- p < 0.05 不是“结论有 95% 概率正确”，只是“按 0.05 的显著性水平拒绝 H0”。
- 两类错误：第一类（假阳性，α）、第二类（假阴性，β）；功效 = 1−β，样本量、效应大小、α 三者共同决定功效。
- 常见坑：多重比较不校正（测 20 个指标总有一个“显著”）、p-hacking（试到显著为止）、只报 p 值不报效应大小与置信区间。

## 6. 回归：从相关到预测

- 一元线性回归：y = a + b·x + ε，b 的含义是 x 每变 1 单位 y 的平均变化量，不是因果。
- 判定系数 R²：模型解释了多大比例的方差；R² 高不等于能因果解释，更不等于外推可靠。
- 残差图必看：残差随机散布才算拟合到位；残差有弯曲/漏斗形，说明漏了非线性项或异方差。
- 相关 ≠ 因果：辛普森悖论（分组后趋势反转）是回归分析里最经典的翻车现场。

## 7. 与机器学习的连接

- 损失函数就是统计假设：MSE 对应高斯噪声假设，交叉熵对应伯努利/多分类假设。
- 过拟合的统计视角：训练集是样本，泛化误差 = 偏差² + 方差 + 噪声；正则化是在偏差和方差之间做交易。
- 评测指标的统计视角：准确率、召回率、F1 都是样本统计量，样本量小时要报置信区间；两个模型差 0.5 个点先做显著性检验再下结论。
- 关联：[AI与大模型/机器学习基础.md](AI与大模型/机器学习基础.md)、[AI与大模型/模型评测方法.md](AI与大模型/模型评测方法.md)。

## 8. 常见坑

- 均值陷阱：收入、延迟这类右偏数据用均值会高估“典型值”，先看中位数和分位数。
- 幸存者偏差：只看活下来的样本（上线的模型、存活的公司）会系统性低估失败率。
- 基率忽视：罕见病筛查准确率 99% 也可能阳性预测值很低，因为先验概率太小。
- 样本量幻觉：n=30 和 n=30000 的结论可信度不在一个量级，报结论先报 n。

## 面试与自测

1. 均值和中位数什么时候差很多？说明数据有什么特征？
2. p < 0.05 到底是什么意思？为什么不能说“结论有 95% 概率正确”？
3. 贝叶斯公式里先验、似然、后验各起什么作用？
4. R² 很高能不能说明模型可以因果解释？为什么？
5. 两个模型在评测集上差 0.5 个点，能直接说 A 比 B 好吗？还缺什么？

### 参考答案

1. 数据偏态严重或有极端值时。右偏（如收入、延迟）均值被极端大值拉高，均值远大于中位数；此时中位数更能代表“典型值”。
2. p 值是在原假设 H0 成立的前提下，看到当前或更极端数据的概率。p < 0.05 只表示“按 0.05 显著性水平拒绝 H0”，不是结论正确的概率；后者需要贝叶斯框架下的后验概率。
3. 先验是动手前已有的判断，似然是数据在参数下的出现概率，后验是结合两者后的修正判断；后验 ∝ 似然 × 先验，证据越强，先验影响越小。
4. 不能。R² 只表示模型解释了多大比例的方差，不涉及因果；混杂变量、数据泄露、分布外推都可能让高 R² 的模型在因果上站不住。
5. 不能。0.5 个点可能是样本噪声：要报样本量与置信区间，并做显著性检验（或看多次运行的方差）；样本量太小的话，差值本身就不稳定。
