# 单调栈与单调队列

单调栈和单调队列共享一个思想：维护一个单调的结构，把“不需要再比较的元素”提前扔掉，让每个元素最多入出一次，从而把 O(n²) 的暴力比较降到 O(n)。

## 单调栈：下一个更大元素

模板（栈内存下标，栈内从栈底到栈顶单调递减）：

```python
def next_greater(nums):
    res = [-1] * len(nums)
    st = []  # 存下标，nums[st] 从栈底到栈顶单调递减
    for i, x in enumerate(nums):
        while st and nums[st[-1]] < x:
            res[st.pop()] = x  # 当前元素就是被弹出元素的下一个更大元素
        st.append(i)
    return res
```

注意比较符：`while nums[st[-1]] < x` 弹出，相等的不弹，所以求的是“严格更大”；把 `<` 换成 `>`，栈内就变成单调递增，求的是下一个更小元素。

### worked 例

`nums = [2, 1, 2, 4, 3]`，逐步走：

- 2 入栈，栈 `[2]`；1 入栈，栈 `[2, 1]`。
- 2 到来：弹出 1（1 的下一个更大是 2），栈 `[2, 2]`。
- 4 到来：弹出两个 2（它们的下一个更大都是 4），栈 `[4]`。
- 3 入栈，栈 `[4, 3]`；结束时栈里剩的 4、3 没有下一个更大元素，填 -1。

结果 `[4, 2, 4, -1, -1]`。

### 应用：柱状图最大矩形

同样是单调栈：弹出高度 `h` 时，`h` 能向左右扩展到的边界就是当前栈顶和当前下标，宽 = `i - left - 1`。

```python
def largest_rectangle(heights):
    hs = heights + [0]  # 末尾哨兵，把栈里剩的元素全部弹出来算一遍
    st, best = [], 0
    for i, h in enumerate(hs):
        while st and hs[st[-1]] > h:
            height = hs[st.pop()]
            left = st[-1] if st else -1
            best = max(best, height * (i - left - 1))
        st.append(i)
    return best
```

worked 例：`heights = [2, 1, 5, 6, 2, 3]`，最大矩形是 `10`。关键一步：处理到下标 4（值为 2）时弹出高度 5，左边界是下标 1，宽 `4 - 1 - 1 = 2`，面积 `5 * 2 = 10`；弹出高度 6 时宽 1，面积 6；最终最大值就是 10。

## 单调队列：滑动窗口最大值

模板（双端队列存下标，队内元素对应的值单调递减）：

```python
from collections import deque

def sliding_max(nums, k):
    dq, res = deque(), []
    for i, x in enumerate(nums):
        while dq and dq[0] <= i - k:  # 队首已滑出窗口，扔掉
            dq.popleft()
        while dq and nums[dq[-1]] < x:  # 队尾比当前值小的，永远当不了窗口最大值
            dq.pop()
        dq.append(i)
        if i >= k - 1:
            res.append(nums[dq[0]])  # 队首就是当前窗口最大值
    return res
```

### worked 例

`nums = [1, 3, -1, -3, 5, 3, 6, 7]`，`k = 3`，结果 `[3, 3, 5, 5, 6, 7]`。走前两步看机制：下标 0（值 1）入队；下标 1（值 3）到来，队尾 1 比 3 小被弹出，队首是 3，第一个窗口 `[1, 3, -1]` 的最大值就是 3；下标 2（值 -1）入队排在 3 后面，因为它可能在 3 滑出窗口后成为最大值——这就是“比当前值小的元素还要留着”的原因：它们是未来的候选。

## 为什么是 O(n)

单调栈和单调队列都是：每个元素最多入栈/入队一次、出栈/出队一次，总操作不超过 `2n` 次，所以是 O(n)。不是“内层 while 看起来像嵌套循环就是 O(n²)”——while 每弹一个元素，那个元素就再也不会进来了，均摊下来每个元素只被处理常数次。

## 适用场景对比

| 工具 | 解决的问题 | 典型题 |
|---|---|---|
| 单调栈 | 找每个元素的“下一个更大/更小” | 下一个更大元素、柱状图最大矩形、接雨水 |
| 单调队列 | 维护滑动窗口内的最值 | 滑动窗口最大值、滑动窗口最小值 |

## 常见误区

- 术语混淆：有人把“从栈底到栈顶单调递减的栈”叫单调递减栈，有人按弹出顺序叫它单调递增栈；做题时不要背名字，按“栈内单调性 + 比较符”对号入座：求下一个更大 → 栈内递减、`<` 弹出；求下一个更小 → 栈内递增、`>` 弹出。
- 滑动窗口最大值用堆：堆顶可能是已滑出窗口的元素，要反复判断过期，写法比单调队列啰嗦且常数更大；窗口最值优先用单调队列。
- 相等元素的处理要先定好：求“严格更大”时相等不弹，求“更大或相等”时相等也弹，两者结果不同，写代码前先确认题意。

## 面试与自测

1. 单调栈里有个 while 嵌套在 for 里，为什么整体还是 O(n) 而不是 O(n²)？
2. 滑动窗口最大值为什么不直接用一个普通队列（或堆）来维护？
3. 求下一个更大元素时，栈内应该维护递增还是递减？比较符用 `<` 还是 `>`？

### 参考答案

1. 因为每个元素最多入栈一次、出栈一次：while 每弹出一个元素，那个元素就永久离开栈了；整个过程入栈 n 次、出栈至多 n 次，总操作 O(n)，均摊到每个元素是常数。
2. 普通队列只能做到先进先出，取最大值要扫一遍窗口是 O(k)；堆虽然能取最大值，但堆顶可能是已滑出窗口的过期元素，要反复清理。单调队列让队首恒为窗口最大值，过期判断和最值获取都是 O(1)。
3. 维护从栈底到栈顶单调递减的栈，比较符用 `<` 弹出：当前元素大于栈顶时，栈顶元素的下一个更大元素就是当前元素；相等的不弹，求的是严格更大。若比较符换成 `>`，栈内变成单调递增，求的是下一个更小元素。
