# 数据库知识点地图

## 知识点清单

- [[MySQL-数据库]]：索引、EXPLAIN、事务、SQL 基础（项目用 OceanBase MySQL 模式）
- [[MySQL-binlog]]：binlog 格式与参数、mysqlbinlog 解码、主从复制、CDC、PITR 与闪回（从 MySQL-数据库拆分）
- [[Redis]]：数据结构、缓存、分布式锁
- [[Elasticsearch]]：全文搜索、索引设计
- 消息队列：[[RocketMQ]]、[[Kafka-消息队列]]

- 索引与事务：[[MySQL-索引与执行计划]]、[[MySQL-事务与MVCC]]
- [[OceanBase]]：分布式数据库、MySQL 模式差异与开发注意（项目在用）
- Redis 专题：[[Redis-缓存问题与分布式锁]]、[[Redis-持久化与淘汰策略]]
- 扩展与集群：[[分库分表]]、[[Redis-集群]]

## 学习路径

```text
[[MySQL-数据库]]（索引 → 事务 → binlog）
  → [[Redis]]（缓存与回表配合）
  → [[Elasticsearch]]（搜索与 CDC 同步链路）
  → [[RocketMQ]] / [[Kafka-消息队列]]（异步与削峰）
```
