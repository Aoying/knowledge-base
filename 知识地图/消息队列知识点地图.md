# 消息队列知识点地图

消息队列领域的导航地图：知识点清单、选型关系与学习路径。目录负责存储（`消息队列/`），本页负责导航。

## 知识点清单

- [[RocketMQ]]：消息模型、事务消息、消费位点与重放
- [[Kafka-消息队列]]：分区与副本、ISR、消费者组与 lag 排查
- [[Kafka与RocketMQ对比]]：架构、消息模型、选型建议
- [[消息可靠性]]：不丢不重横向专题（三档语义、两家机制对比、消费端幂等模式）

## 选型关系

- 高吞吐日志/流式管道 → Kafka；业务消息（事务、顺序、延迟） → RocketMQ，对比细节见对比篇。
- 前置知识：[[数据结构与算法]]（队列与堆）、[[操作系统-进程线程]]（生产者-消费者模型）。

## 学习路径

[[RocketMQ]] 基础 → [[Kafka-消息队列]] 基础 → 对比篇选型 → 疑难杂症索引中的消息队列条目。
